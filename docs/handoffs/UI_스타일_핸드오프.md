# UI 스타일 핸드오프 — "See you on the other side"

> **용도:** 이 문서 하나만 보고 게임의 분위기에 맞는 **UI 디자인(버튼·패널·아이콘·프레임 등)** 을 외부(예: Claude 디자인/아티팩트)에서 뽑아오기 위한 브리프. 코드 접근 없이도 이해되게 self-contained 로 정리했다.
> **뽑아온 결과를 어떻게 붙이나:** 게임의 모든 UI 스타일은 `scripts/ui/UITheme.gd` 한 곳에서 나온다(색·크기·StyleBox). 그래서 산출물은 ① 색/치수 스펙(이 문서 값 갱신) 또는 ② **9-patch PNG 텍스처**(버튼·패널 배경)면 그대로 `UITheme` 에 꽂을 수 있다. §7·§8 참고.

---

## 1. 게임이 뭔가 (분위기의 뿌리)

비동기 로그라이트. 매년 재앙을 멈추러 **원정대가 사막으로 떠나고 거의 다 죽는다.** 플레이어는 그 원정대를 거듭 보내는 총괄자. 모래폭풍이 글씨를 지우는 세계라 말은 안 남고 **물건만 남는다** — 죽기 전 단 한 번, 다음 원정대에게 물건 하나를 남긴다. 제목은 남에게 하는 작별이 아니라 미래의 '나'에게 하는 약속.

- **정서:** 담담하고 서늘함. 쓸쓸함·체념 + 릴레이로 이어지는 옅은 희망. 과장·활기·네온 금지.
- **키워드:** 사막, 모래폭풍, 낡은 양피지 지도, 가죽·캔버스 장비, 세피아 잉크, 밤하늘, 흔적, 유한함.
- **레퍼런스 톤:** 반지의 제왕 고지도 + 빛바랜 탐험 일지 + 어스름한 사막 유화. (밝고 깨끗한 앱 UI 아님.)

## 2. 비주얼 아이덴티티

- **두 세계의 표면이 공존한다:**
  - **양피지/지도 표면** — 지도·도착 단면 화면. 빛바랜 종이 위 세피아 잉크 선. (밝은 베이지 바탕 + 어두운 잉크)
  - **밤/어스름 표면** — 타이틀·오프닝·마을·가방·설정 등 UI 화면. 어두운 남색 밤하늘 배경 위 밝은 글자 + 모래색 강조. (현재 UI 크롬은 이 어두운 표면 위에 얹힌다)
- **질감:** 매끈·플랫이 아니라 **낡고 손때 묻은** 느낌 — 종이결, 가죽, 그을린 가장자리, 은은한 그레인. 단 **과한 텍스처·노이즈는 금지**(웹 경량 + 가독).
- **모서리:** 살짝 둥근(라운드 8~16px). 완전 각지거나 완전 알약형 아님.
- **채도 낮게, 따뜻하게.** 회청색 계열보다 **모래·가죽·세피아**로 기울면 게임에 더 맞는다(현재 UI가 살짝 차가운 편 → 따뜻하게가 개선 방향).

## 4. 타이포그래피

- **모든 UI 텍스트가 한국어다.** → 디자인·폰트는 **반드시 한글 글리프 포함**. (한글 없는 폰트 쓰면 웹에서 전부 두부 □ 로 깨짐 — 실제 겪은 블로커.)
- **현재 폰트(전부 OFL, 임베드됨):**
  - 본문·제목 = **마루 부리(MaruBuri)** — 부드러운 명조. 프로젝트 기본.
  - 영문 타이틀 = **Cinzel** — 비문풍 세리프(로고 "See you on the other side" 전용).
  - 지명·붓 느낌 = **나눔손글씨 붓(NanumBrushScript)** — 지도 위 지명 등. (본문엔 안 씀)
  - (예비: 나눔명조·나눔고딕 보유)
- **타입 스케일(px, 세로 600 논리해상도 기준):** DISPLAY 46 / H1 34 / H2 27 / BODY 26 / LABEL 22 / SMALL 18 / TINY 14. 줄간격 넉넉히(line_spacing 8).
- **장식 유니코드(✕, − 등) 금지** — 임베드 폰트에 글리프 없으면 두부. 아이콘 필요하면 그림/절차적 draw 로.

## 5. 레이아웃 · 폼팩터

- **터치 우선, 두 폼팩터 지원:** **데스크톱(가로)이 기본**, 스마트폰(세로)도 지원. 웹 빌드라 폰 브라우저에서 그대로 플레이.
- **중앙 최대폭 컬럼:** 콘텐츠는 화면 중앙에 폭 제한 컬럼(최대 `520px`)으로. 세로폰에선 거의 꽉 차고, 가로에선 가운데 카드처럼 보인다.
- **큰 터치 타깃:** 주요 버튼 높이 `76px`, 보조 `60px`. 손가락 기준 넉넉히, 간격 여유.
- **여백:** 화면 가장자리 `32px`, 카드 안쪽 `28px`, 위젯 간격 `18px`, 노치 안전 `24px`.
- **스크롤:** 콘텐츠가 길면 세로 스크롤(하단 버튼까지 도달). 가로 스크롤 없음.

## 6. 컴포넌트 인벤토리 (디자인이 필요한 것들)

각 항목의 **현재 모습**과 **디자인에서 다뤄줄 상태/변형**:

1. **주요 버튼 (primary)** — 풀폭, 큰 터치. 상태: normal / hover / pressed / disabled. (예: "원정 떠나기", "떠난다")
2. **보조 버튼 (secondary)** — 낮고 작음. 같은 4상태. (예: "다시 뽑기", "← 뒤로")
3. **알약 버튼 (pill/outline)** — 색을 직접 지정하는 강조/외곽선 버튼(설정 등).
4. **카드/패널** — 둥근 면 + 테두리 + 안쪽 여백. 모달 콘텐츠·죽음/결말 카드가 이 위에 얹힌다.
5. **모달 뒤 스크림** — 화면 어둡게(반투명 검정).
6. **라벨 계층** — 제목(H1)·본문·보조설명(muted)·강조(sand)·위험(danger).
7. **드롭다운(OptionButton)** — 대장 특기·주머니 도구 선택.
8. **슬라이더** — 설정(음량). 현재: 얇은 트랙 + 모래색 채움 + 모래알 그래버.
9. **가로 구분선(hairline)** — 얇은 모래색 선.
10. **가방 슬롯** — 6칸 그리드. 담긴 칸(아이템 아이콘+이름) / 빈칸(움푹). 가죽틀 안. (배낭 그림 위에 얹힘)
11. **아이템 아이콘 8종** — 물통·식량·말린고기·로프·은신막·약초·부싯돌·정화천. (별도 아트 프롬프트 있음: `docs/external/art_prompts.md §9`)
12. **자원 HUD** — 원정 중 상단 바. 물/식량 큰 수치 + 보유 도구 요약 + "조사 N번 가능".
13. **지도 노드/길** — 양피지 위 세피아 아이콘 + 잉크 트레일(가본 길=실선, 미지=점선) + 원정대 마커.
14. **도착 단면의 조사 지점 마커** — 붉은 링(조사 가능)/체크(완료)/흐림(잠김).
15. **선택지 버튼(blind choice)** — 결과를 눌러봐야 아는 카드형 버튼(조건/결과 노출 규칙 있음).
16. **책갈피(기록지) 버튼** — 화면 구석 상시 버튼.

## 7. 제약 (반드시 지킬 것 — 웹 빌드)

- **셰이더 / GPUParticles 금지.** GL Compatibility + 웹 export 에서 깨진다. 효과는 전부 CPU/절차적.
- **에셋 경량.** 웹 빌드가 이미 무겁다(막 55MB→46MB 로 줄임). UI 텍스처를 쓰면 **작게·적게**. 9-patch 는 몇십 px 짜리 타일로 충분(늘려 쓰니까).
- **투명 PNG 주의:** 이미지 생성기는 진짜 투명을 못 만들고 체커보드를 *그림으로* 그린다. → **흰 배경(#FFFFFF)으로 뽑고**, 넣기 전 코드로 흰색→투명 변환한다. 절대 체커보드 배경·박힌 텍스트로 주지 말 것.
- **한글 글리프 필수**(§4). 폰트 바꾸면 웹에서 한글 실렌더 확인.
- **9-patch 규칙:** 텍스처를 주면 **늘어나지 않을 모서리 여백(px)** 을 함께 알려줄 것(예: 상하좌우 16px 고정). 안 그러면 늘릴 때 테두리가 뭉갠다.

## 8. 뽑아올 산출물 (이상적 형태)

**한 벌의 UI 킷**으로, 게임 톤(§1·§2)과 팔레트(§3)에 맞게:

- **버튼 배경 9-patch** — primary/secondary, 4상태(normal/hover/pressed/disabled). 또는 색·테두리·라운드 스펙만.
- **패널/카드 9-patch** — 양피지 또는 가죽 면 + 낡은 테두리.
- **가방 슬롯 프레임** — 담긴/빈 칸.
- **구분선·모서리 장식**(선택) — 낡은 잉크 오너먼트.
- **아이콘 스타일 가이드** — 아이템 8종·자원 표시가 일관되게(선 두께·세피아 톤).

**형식:** 9-patch 는 PNG(흰 배경→투명 규칙, 모서리 여백 명시). 색/치수 변경만이면 이 문서의 §3·§4·§5 값을 갱신하는 표로 줘도 된다. **SVG/피그마보다 "게임에 바로 꽂을 PNG 타일 + 여백 수치 + HEX"** 가 통합이 빠르다.

## 10. 요약 한 줄

**"빛바랜 사막 탐험 일지"** — 저채도 세피아·모래·가죽, 부드러운 명조 한글, 낡았지만 정갈한 손때. 밝고 매끈한 앱이 아니라, 모래폭풍에 반쯤 지워진 낡은 장부를 만지는 감촉. 지금 UI는 골격이 잘 잡혀 있으니(§3 `UITheme`), **차가운 회청색을 따뜻한 가죽·양피지로 옮기고 손때(질감)를 입히는 것**이 핵심.
