# 핸드오프 모음

> 다른 대화(예: Claude 웹·디자인)에 **그대로 붙여넣어** 설계·디자인을 이어가기 위한 self-contained 브리핑들.
> 저장소 접근 없이도 읽히게 맥락을 다 담았다. 여기저기 흩어져 찾기 번거로워 한곳에 모았다.
> (프로젝트 현재 상태의 단일 진실은 여전히 `../design/00_START_HERE.md`. 이 폴더는 외부 의뢰용 브리프 보관소.)

## 쓰는 법

- **외부에 의뢰할 때:** 해당 파일 내용을 통째로 복사해 다른 대화에 붙인다. 파일 하나로 맥락이 완결된다.
- **결과 통합:** UI 산출물은 `UITheme.gd` 또는 9-patch PNG로. 논의 결과(규칙 변경)는 기획서·`00_START_HERE.md`에 반영.
- **새 핸드오프를 만들면** 이 폴더에 두고 위 표에 한 줄 추가한다.
