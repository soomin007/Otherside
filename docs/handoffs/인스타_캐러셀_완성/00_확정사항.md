# 캐러셀 확정 사항 — 피드백 시 재론 금지 목록

> See you on the other side 인스타 캐러셀 (1080×1350, 10장). 아래는 제작자가 이미 검토·결정한 사항이므로 피드백에서 다시 제안하지 말 것. 이 외의 부분(레이아웃 디테일, 가독성, 카피 다듬기 등)은 자유롭게 지적.

## 방향·구성 (확정)
1. **포스터는 인게임 화면처럼.** 문구도 인게임 어법. 웹 광고·책 광고 톤 금지.
2. **순서(후크 우선) 확정**: 1 타이틀 → 2 오프닝 지운다("남길 수 있는 것은 단 하나") → 3 남기기 → 4 오프닝 떠난다 → 5 배낭(연출) → 6 탐험·조사 → 7 위협(연출) → 8 새길 말 → 9 지도 → 10 CTA. 06·07을 앞으로 당겨 고유 규칙으로 시작하는 구조는 이미 적용됨.
3. **5·7번은 인게임 스크린샷 대신 연출샷** (레이어 합성/전용 아트). 스크린샷 복귀 제안 금지.
4. **8번은 단어 풀 전체를 보여주지 않는다.** 물통 + 흔적 태그(「또」「봐」) + 옅은 예시 단어 몇 개로 암시. 그리드 복귀 제안 금지.
5. **"넘겨서 계속 →"은 1번에만.** 매 슬라이드 반복 금지 확정.

## 문구 (확정)
6. 표제는 **명령형·명사형, 문장 끝 마침표 없음** ("무엇을 지고 갈 것인가", "폭풍 앞에서 선택하라", "지도를 밝히기 위해 더 멀리 탐험하라").
7. **em dash(—) 절대 금지.** 한국어 자연스러운 어투, 영어 직역투 금지.
8. "무료", "한 원정 N분" 류 표기 **안 씀** (웹 배포라 자명 / 미측정).
9. 출시 문구는 "지금 플레이 가능" 계열 (날짜 없음).
10. 7번 선택지는 "잦아들 때까지 버틴다 / 폭풍을 뚫고 나아간다" ('장막' 단어 회피 결정).
11. 3번(남기기) 소문구 "긴 말은 남길 수 없다. 물건 하나, 거기 새긴 한두 마디뿐." (08과의 모순 해소 완료).
12. 용어는 인게임 기준: "죽은 자리" (쓰러진 자리 아님).
13. 10번 CTA: "당신의 흔적이 다음 원정대에게 남는다" + "프로필 링크에서 바로 플레이" + URL. "원정을 떠난다" 버튼은 뺌.

## 디자인 (확정)
14. 폰트: 마루부리(본문·표제) + Cinzel(URL). **나눔붓 등 붓글씨 포스터 사용 금지.**
15. 오프닝(2·4번) 텍스트 배경은 **넓고 진한 타원 비네트 + 하단 그늘**. 잉크 번짐 등 다른 처리 제안 금지.
16. 스크린샷의 **빨간 책갈피 리본은 제거** 처리 (지도의 붉은 원·화살표는 인게임 요소라 유지).
17. 색 강조는 모래색 #D6B278, 슬라이드당 핵심 1~2곳.
18. 로고는 글자 실측 중심 기준 정렬(translateX(-45.5%)) — 모래 이펙트 때문에 이미지 중심과 다름.
19. 9번 지도는 노드 아이콘이 큰 신규 스크린샷 사용 (구판 복귀 금지).
