# UI 그래픽(아이콘·마커·픽토그램) 발주 핸드오프 — "See you on the other side"

> **용도:** 이 문서 하나만 보고, 지금 코드로 대충 그려 쓰고 있는(절차적 draw) UI 그래픽 전부를
> **실제 그림 에셋**으로 뽑아오기 위한 브리프. 코드·저장소 접근 없이 읽히게 self-contained 로 정리했다.
> **함께 볼 것:** `handoff_ui_map_now.png`(지도 화면 현재 모습) · `handoff_ui_marks_now.png`(게임 안 범례 페이지).
> 톤·팔레트의 더 긴 배경은 `UI_스타일_핸드오프.md`(2026-07-03)에 있으나, **수치가 갱신된 이 문서가 우선**한다.
> 작성: 2026-07-11.

## 1. 게임이 뭔가 (그림이 놓일 세계)

비동기 로그라이트. 모래폭풍이 지날 때마다 재앙을 멈추러 **원정대가 사막으로 떠나고 거의 다 죽는다.**
플레이어는 그 원정대를 거듭 보내는 총괄자. 모래폭풍이 글씨를 지우는 세계라 말은 안 남고 **물건만 남는다.**
죽기 전 단 한 번, 다음 원정대에게 물건 하나를 남긴다. 원정대는 대장 1 + 대원 4의 **행렬**로 걷고,
위험한 순간마다 한 사람씩 스러진다. 아무도 잃지 않고 닿아야 진짜 결말(재회)이 열린다.

- **정서:** 담담하고 서늘함. 쓸쓸함 + 릴레이로 이어지는 옅은 희망. 과장·활기·네온 금지.
- **미학 원칙("각인"):** UI 는 상자·버튼 프레임을 지양하고, **어둠 위에 새긴 글자와 잉크 기호**로만 선다.
  그림 요소도 "지도에 손으로 그려 넣은 잉크 낙서 / 낡은 장부의 기호"로 읽혀야 한다.
- **레퍼런스 톤:** 반지의 제왕 고지도 + 빛바랜 탐험 일지 + 어스름한 사막 유화.

## 2. 기술 환경 (반드시 알고 그릴 것)

| 항목 | 값 |
|---|---|
| 엔진 | **Godot 4.6** (GDScript) · 2D |
| 렌더러 | **GL Compatibility** (모바일 웹 호환용 저사양 파이프라인) |
| 배포 | **웹(HTML5) export → GitHub Pages.** 폰·데스크톱 브라우저에서 플레이 |
| 화면 | **가로 16:9 기준.** 지도 화면은 1280×720 고정 스테이지를 contain 스케일. 그 외 화면은 논리 세로 600px 기준으로 비례 확대 |
| 입력 | 터치 우선(탭 위주). 인터랙티브 요소 최소 ~56px |
| 효과 제한 | **셰이더·GPU 파티클 사용 불가.** 글로우·번짐·그림자는 **그림에 구워서(bake)** 줄 것. 움직임은 우리가 CPU 파티클·코드 트윈으로 처리 |
| 애니메이션 | GIF 불가. **정지 1장이 기본**, 꼭 필요하면 2~4프레임 시퀀스(PNG 여러 장 또는 가로 스프라이트시트) |
| 용량 | 웹 빌드 다이어트 중(전체 ~28MB). 아이콘류는 **파일당 수십 KB급**, 원본 크기는 표시 크기의 2배(@2x)면 충분 |

### 파일 형식 (중요 — 실제로 겪은 함정)

- **투명 PNG.** 단, AI 생성기의 "가짜 투명"(체커보드를 그림으로 그린 것) 금지.
  진짜 알파를 못 만들면 **순백(#FFFFFF) 배경**으로 줄 것 — 흰색→투명 변환은 우리가 코드로 한다.
- **그림 안에 글자 넣지 말 것.** 모든 텍스트는 게임 폰트(한글 명조)가 렌더한다.
- 한 세트는 **일관된 선 굵기·톤**으로. 낱개 파일이면 이름은 자유(우리가 `NN_카테고리_이름.png`로 정리한다).
- 시트로 줄 경우 셀 경계(px)를 명시.

## 3. 두 배경, 두 잉크 (모든 기호는 두 판이 필요할 수 있다)

그림이 얹히는 표면이 둘이다. **각 기호가 어느 표면용인지 §5 표에 적었다.**

1. **양피지(지도·일지)** — 바탕 `#D1BD91`, 기호는 **세피아 잉크** `#45301C`(진함) / `#80694A`(빛바램).
   포인트 붉은 잉크 `#8C331F`(원정대 마커·책갈피). 낡은 깃펜/붓 선, 약간 거친 가장자리.
2. **어스름(그 외 화면)** — 바탕 거의 검정 `#08070A`~`#2A1C10`, 기호는 **아이보리** `#F6ECD4` /
   강조 모래색 `#D6B278` / 보조 `#9E9EB0` / 위험 `#E06B61`. 어둠 위에 새긴 각인 느낌.

자원 구분색(양피지 위 안료 점): 물 `#40708C` · 식량 `#A17030` · 장막 `#73824D` · 도구 `#856B94`.
크림 후광(가독용 빛 웅덩이): `#E9D6AF`.

## 5. 발주 품목 (우선순위순)

각 항목: 쓰임 · 표시 크기(화면 px, 원본은 2배) · 표면 · 상태/변형.

### ① 사람 픽토그램 세트 ★ 이번 발주의 계기

원정대가 "숫자"가 아니라 "사람"으로 보이게 하는 핵심. 잉크판(양피지)과 아이보리판(어둠) 둘 다.

| 품목 | 쓰임 | 표시 크기 | 변형 |
|---|---|---|---|
| 걷는 원정대원 | 지도 마커 뒤에 줄지어 따라 걷는 행렬(대장+4), 좌 칼럼 "행렬" 줄 | 14~20px 높이 | 걷는 자세 2변형(줄 세울 때 단조로움 방지). 두건·천 두른 사막 여행자 실루엣 |
| 대장 | 행렬 맨 앞(지팡이·앞선 자세 등 미세 구분) | 14~20px | 1 |
| 스러진 자리 | 대원을 잃은 자리 — 행렬 줄에서 사람 대신 남는 것 | 12~16px | 낮은 모래 무더기 or 쓰러진 형체, 흩어지는 알갱이 몇 점 |
| 웅크린 낙오자 | 지도에서 "뒤처진 이가 기다린다" 마커(지금은 코드로 그린 웅크린 실루엣) | 16~20px | 1 (온기 후광은 우리가 얹음) |
| 큰 행렬 실루엣 | 일지·엔딩·손실 연출 등 큰 자리(선택 — 여유 되면) | 40~80px | 5인 행렬이 걷는 옆모습 한 장 |

### ② 지도 마커·기호 세트 (양피지 위 잉크)

현재 전부 코드로 그린 점·선. 첨부 `handoff_ui_marks_now.png`(게임 안 범례)가 현재 모습.

| 품목 | 쓰임 | 표시 크기 | 변형 |
|---|---|---|---|
| 자원 점 | 이전 원정대가 남긴 물건 위치(지도) | 표시 9~14px | 4색(물·식량·장막·도구 — §3 안료색) × 공통 형태. 잉크 링 + 안료 점 + 크림 후광을 한 장에 bake |
| 로프 다리 | 차단 노드에 로프가 걸려 있음(영구 통과) | 12~16px | 1 |
| +N 배지 | 흔적이 상한 넘게 쌓인 자리 요약(숫자는 폰트가 씀 — 바탕만) | 14px | 1 |
| 원정대 위치 태그 | 현재 노드 위 작은 표지(지금은 삼각형+글자) | 12px | 1 |
| 조사 가능 원 | (참고만 — 노드를 감싸는 손그림 잉크 원은 "살아있는 잉크"로 코드 유지 확정) | — | 발주 아님 |

### ③ 단면(탐색 화면) 지점 마커

배경이 밝기 제각각인 삽화라, **자체 후광 포함** 한 벌.

| 품목 | 쓰임 | 표시 크기 | 변형 |
|---|---|---|---|
| 주요 지점 | 그 장소의 본 사건(이중 고리) | 40~52px | 기본 / 살핀 뒤(흐림) |
| 보조 지점 | 물·식량·잔일이 있을 수 있는 곳(단일 고리) | 30~40px | 기본 / 살핀 뒤 / 예산 소진(잠김) |
| 조사 램프 점 | 남은 조사 횟수(찬 점/빈 점) | 10~12px | 찬/빈 |

### ④ UI 소품 (어스름 표면)

| 품목 | 쓰임 | 표시 크기 | 변형 |
|---|---|---|---|
| 책갈피 리본 | 화면 우상단 상시(원정 일지 열기) + 일지 챕터 탭 | 폭 38~96×높이 30px | 기본/호버(더 나옴)은 같은 그림 길이 조절 — 9-patch 식으로 좌우 늘어나는 리본이면 최적 |
| 가방 슬롯 틀 | 배낭 6칸 + 주머니 1칸(담김/빈) | 54px | 담긴 칸 / 빈 칸(움푹) |
| 슬라이더 그래버 | 설정 음량·연출(지금은 모래알 점) | 22px | 1 (잉크판도 — 일지 안 슬라이더용) |

## 6. 산출물 정리 (요약)

- **필수:** ①사람 세트(잉크+아이보리 두 판) ②지도 기호 세트 ③단면 마커 세트.
- **선택:** ④UI 소품, ①의 큰 행렬 실루엣.
- 형식: 투명 PNG(또는 순백 배경), @2x, 글자 없음, 세트 내 선 굵기·톤 통일.
- 각 파일이 §5 의 어느 품목인지 알 수 있게 이름 또는 목록을 같이 줄 것.
- 색은 §3 팔레트 안에서. 두 표면(어둠 `#08070A` / 양피지 `#D1BD91`) 위에 얹어 보고 확인해 줄 것.
