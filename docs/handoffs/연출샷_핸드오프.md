# 연출샷 핸드오프 — 인스타 캐러셀 5번(배낭 챙기기) · 7번(위협)

> 용도: Claude Code에서 홍보용 연출 이미지 2장을 생성/합성하기 위한 사양.
> 공통 원칙: **텍스트 없는 아트만** 만들 것. 타이포(제목·라벨·선택지)는 포스터 HTML 쪽에서 얹는다.
> 톤: 기존 키아트(29_타이틀_키아트, 24~28_오프닝)와 같은 색온도. 팔레트: sand #D6B278, ivory #F6ECD4, 잉크 #45301C, 무대 #08070A.

## 공통 규격
- 캔버스: **1080×1080 이상** (포스터가 4:5·1080×1350이므로 세로로 여유 있게 1080×1200 권장)
- 상하 20~25%는 어둡게 떨어지는 여백 (위: 제목 52px, 아래: 캡션 2줄이 얹힘)
- 폰 폭 400px로 축소돼도 형태가 읽히는 큰 실루엣 위주. 잔 디테일·작은 글씨 금지
- UI 요소(빨간 리본, HUD 수치, 하단 버튼) 넣지 말 것

## 샷 A — 배낭 챙기기 (슬라이드 5 "무엇을 지고 갈 것인가")
현재 문제: 인게임 스크린샷(1280×720 전폭 테이블)은 폰에서 아이템이 좁쌀만 해짐.

- **구도**: 창고 테이블을 비스듬히 내려다보는 클로즈업. 아이템 **4개만** 크게 — 물통, 식량 자루, 로프, 장막 (기존 촬영 에셋 재사용 가능: 30_아이템_물통, 33_아이템_로프 등)
- 아이템이 화면 폭의 대부분을 차지하게. 하나(물통)는 손에 들려 있거나 배낭에 반쯤 담긴 상태면 "고르는 중"이라는 행위가 전달됨
- **조명**: 왼쪽 위 랜턴 하나, 따뜻한 앰버. 배경 창고(warehouse_land)는 어둡게 아웃포커스
- 하단 1/4은 테이블 그림자로 자연스럽게 어두워질 것 (캡션 자리)
- 포스터가 얹을 텍스트: 제목 "무엇을 지고 갈 것인가" / 캡션 "짐의 무게…" 2줄 → 이미지에는 절대 글자 넣지 말 것

## 샷 B — 위협 (슬라이드 7 "폭풍 앞에서 선택하라")
현재 문제: 모달+배경 두 층이 겹쳐 어수선, 선택지 텍스트가 폰에서 안 읽힘.

- **구도**: 화면 위 2/3를 가득 채우는 모래폭풍 벽(55_막간_폭풍 톤). 아래 1/3, 폭풍 앞에 **실루엣 원정대 행렬 4~5명**이 아주 작게 — 압도적 스케일 대비가 핵심
- 대장(60_사람_대장)이 행렬 맨 앞에서 폭풍을 올려다보며 멈춰 선 순간. "선택의 기로"라는 정지감
- 폭풍 상단은 화면 밖으로 뻗어나가 끝이 안 보이게
- **색**: 폭풍은 탁한 모래빛~암갈색, 하늘 상단은 거의 검게. 인물 실루엣 주변만 옅은 역광
- 하단 어두운 전경(모래 언덕 그림자)에 캡션 자리 확보
- 포스터가 얹을 텍스트: 제목 + 선택지 2개("여분 장막을 친다 / 그래도 강행한다"를 각인형 타이포로) → 이미지에는 글자 없음
