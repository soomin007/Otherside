# 핸드오프: 원정 일지 "책장 넘김" 연출

> 외부(HTML 프로토타입 등)에서 자연스러운 책장 넘김을 만들어 오면, 그 타이밍·형태 값을 게임(Godot 4.6)에 이식한다.
> 기존 패턴: `design_handoff_expedition_ui/` 처럼 **HTML 목업 + 정량 값(타이밍·곡선·수치)** 으로 받으면 된다.

## 원정 일지란 (맥락)

이 게임의 **유일한 장부 UI** — 기록·조작 안내·설정이 전부 이 한 권에 들어 있다.

- **여는 법**: 모든 화면 왼쪽 가장자리에 **빨간 책갈피 리본**이 삐져나와 있다(호버하면 38→72px 로 더 나옴).
  클릭하면 화면이 어두워지며(책상 어둠) 일지가 펼쳐진다. 바깥 탭 또는 "일지를 덮는다"로 덮는다.
- **생김새**: 어두운 책상 위 **가죽 표지 + 양피지 두 페이지 스프레드**(각 페이지 ~525×640, 괘선·그을린
  가장자리·가운데 접힘 그림자). 제목은 붓글씨(나눔손글씨 붓), 본문은 잉크(#45301C), 강조·수치는 붉은
  잉크(#8C331F). 책 오른쪽 가장자리에 **빨간 챕터 책갈피 3개**가 삐져나와 있다(현재 챕터 = 진하고 길게).
- **챕터 3개** (책갈피로 이동 — 이 전환에 책장 넘김이 들어간다):
  1. **일대기** — 왼쪽: 역대 원정 목록(1번째부터, 결말 한 줄씩 — 도달/재회/스러짐/길 위. 길면 스크롤).
     오른쪽: "행적" 요약(보낸 원정·남긴 흔적·죽은 자리·끝에 닿음 — 값은 붉은 붓글씨) + 덮기.
  2. **조작** — 왼쪽: 안내 텍스트(4장 중 현재 장). 오른쪽: "N / 4 장" + 앞장/다음 장 + 덮기.
     (장 넘기기에도 같은 넘김 연출을 쓸 수 있으면 금상첨화 — 현재는 즉시 교체.)
  3. **설정** — 왼쪽: 소리(전체 음소거 필 + 배경음악/효과음 잉크 슬라이더). 오른쪽: 위험 구역(저장
     데이터 지우기 → 확인 페이지로 전환) + 덮기.

## 무엇이 필요한가

위 일지의 **챕터 전환** 때 낱장 한 장이 넘어가는 연출.

- 책 자체는 절대 움직이지 않는다. **낱장(잎) 하나만** 넘어간다.
- 방향 인식: 뒤 챕터로 = 오른쪽 잎이 왼쪽으로 넘어감 / 앞 챕터로 = 왼쪽 잎이 오른쪽으로 되넘어감.
- 정서: 낡은 일지를 손으로 넘기는 느낌. 빠르되(0.3~0.5s) 팔락이는 종이의 유연함.

## 현재 상태 (1차 근사 — 부자연스러움)

`scripts/ui/Bookmark.gd` `_flip_to()`:
- 잎(FlipLeaf, 양피지 렌더)이 스파인 축으로 **가로 스케일 접기**(scale.x 1→0.03, 0.17s) → 내용 교체 →
  반대편에서 펼치기(0.03→1, 0.18s). 종이 SFX 3종 랜덤.
- 문제: 스케일 축소는 "접힘"이지 "넘어감"이 아니다. 종이의 굽음·뒤집힘·그림자가 없다.

## 제약 (반드시)

- **Godot 4.6, 웹 export — 셰이더/GPUParticles 금지.** CPU 로 가능한 것만: Control 트리, `scale`/`skew`/`rotation`
  트윈, `_draw`(폴리곤·폴리라인·텍스처), CPUParticles2D, 그라디언트 텍스처.
- 3D 노드(SubViewport+3D 페이지) 이론상 가능하나 웹 성능·복잡도상 비권장. 2D 근사 선호.
- 페이지는 절차적 렌더(양피지 색 `#D1BD91`, 가장자리 `#947A52`, 괘선). 텍스처 스냅샷(뷰포트 캡처)로
  현재 페이지 내용을 잎에 박제하는 것은 가능(`get_viewport().get_texture()` — 웹에서도 동작 확인됨).

## 기대 산출물

HTML/CSS(또는 영상) 목업 + 아래 정량 값:
1. **낱장의 변형 시퀀스** — 2D 근사로 표현 가능한 형태(예: 가로 스케일 + skew 조합 키프레임,
   또는 낱장을 세로 스트립 N개로 쪼개 각 스트립의 x/skew 를 시차로 — "휘어지는 종이" 근사).
2. 키프레임 타이밍·이징(예: 0%: 평평 / 40%: 스파인 근처로 들려 skew -8° / 55%: 세로선(두께 0) /
   100%: 반대편에 안착), 전체 길이.
3. 잎 위 그림자/하이라이트(넘어가는 동안 아래 페이지에 지는 그림자 폭·알파, 잎 자체의 명암 변화).
4. (선택) 잎 뒷면 표현 — 넘어간 뒤 보이는 면을 더 밝게/비치게 할지.

## 참고 좌표

- 책: 화면 90%(상한 1080×640), 두 페이지 각 ~525×640, 스파인 = 중앙(간격 16px).
- 챕터 책갈피(빨간 리본)는 책 오른쪽 가장자리 — 연출과 겹쳐도 무방(잎 아래 레이어).
- 종이 SFX 는 게임에 있음(sfx_page 1~3) — 타이밍 싱크 지점만 알려주면 됨.
