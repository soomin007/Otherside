# HANDOFF — 전체 이야기 · 설정 · 흐름 (한눈에 + 이어받기)

> 이 문서는 흩어진 사양을 **통합한 지도**다. 상세 사양의 단일 진실은 여전히 `SYOTOS_기획서_v0.1.md`,
> 할 일은 `backlog.md`, 분업은 `parallel_tracks.md`, 맥락은 `session_logs/`. 여기선 *전체 그림 + 현재 상태 + 이어받는 법*만.
> (오프닝·서사 문구를 나중에 손볼 때, 게임이 어떻게 흘러가고 어떤 설정인지 한 번에 보기 위한 문서.)

---

## 1. 한 문장

**"See you on the other side"** — 매년 재앙을 멈추러 원정대가 떠나고 거의 다 죽는다. 플레이어는 그 원정대를
**거듭 보내는 총괄자이자 매 원정의 대장 자리**에 앉는다. 모래폭풍이 글씨를 지우는 세계에서, 죽기 전 **단 한 번**
다음 원정대에게 *물건*을 남길 수 있다.

- **중심 질문:** *누군가 결국 닿을 것을 알 때, 미래의 나를 위해 지금의 나는 무엇을 포기하는가.*
- **장르:** 비동기 로그라이트(데스 스트랜딩 결 — 각자의 세계에서 진행하되 이전/다음 원정대의 *흔적만* 오간다). 2D, Godot 4.6, 웹 export.

## 2. 설정 / 세계관

- **원정대 릴레이(Expedition 33 결).** 주기적으로 원정대가 재앙을 멈추러 떠나고 거의 다 도중에 죽는다. 한 번에 닿는 이는 없다.
- **모래폭풍 = 세계 법칙.** 주기적으로 길을 쓸고 글씨를 지운다. 그래서 (a) 말(자유 텍스트)은 못 남기고 **물건만** 남긴다,
  (b) 로그라이트 리셋의 서사적 근거(왜 길이 매번 새로 시작되고 흔적이 일부만 남는지).
- **재앙의 정체 = 맥거핀, 결말에서만 드러남.** 플레이 내내 미스터리. 끝에 닿으면 밝혀진다 — 재앙은 괴물이 아니라 **가장 멀리 간 원정대**다(§4 결말).

## 3. 정체성 (헷갈리기 쉬운 핵심)

- 플레이어 = **원정대 총괄자 + 매 원정의 대장 역.** 매 원정은 *매번 다른 사람*이 가고, 플레이어는 그 사실을 *안다*.
- **"과거의 나"가 아니다.** in-world 에서 흔적을 남기고 받는 주체는 '이전/다음 원정대'(다른 사람). 진행은 *총괄자가 잇는 릴레이*.
- **그럼에도 제목의 '나'는 유지:** 메타 층위의 '나'(총괄자 자리)에게 하는 약속. 매 원정을 대장으로 겪은 것은 결국 나다.
- ★ **제일 중요한 설계 축 = 선택의 반영.** 한 선택이 플래그를 남기고, 같은 런과 다음 원정의 이벤트·텍스트를 바꾼다(서울2033·Reigns).

## 4. 전체 서사 아크

서사는 **세 마디**다. 중간은 의도적으로 비어 있다(맥거핀 + self-async 흔적이 채운다).

1. **도입 — 오프닝.** 세계·원정대·모래폭폭·남기기·총괄자 정체성을 담담·서늘하게 소개(재앙 정체는 안 밝힘). 첫 플레이만 자동 재생.
2. **본편 — 반복 원정(중간, 열려 있음).** 정해진 스토리 대사 없음. 이야기는 *플레이어가 겪고 남긴 흔적*으로 생긴다 — 죽은 자리, 남긴 물건, 로프 건 차단, 재방문 변형. "정직한 단서"(거울)이지 각본이 아니다.
3. **결말 — 순환과 재회 (사용자 확정).** 목적지(재앙의 자리)에 닿으면:
   - **기본 = 순환 (서늘함).** 그 자리엔 먼저 간 이전 원정대가 서 있다(재앙 = 가장 멀리 간 원정대). 밀어내고 이번 원정대가 그 자리에 선다 → 다음 원정대가 이곳을 향해 온다(이번 원정대가 다음의 재앙). 릴레이는 멈추지 않는다.
   - **출구 = 재회 (따뜻함, 진짜 엔딩).** 흔적이 충분히 축적되어 *죽지 않고 온전히 닿으면*, 밀어내는 대신 먼저 간 모든 원정대와 함께 건너편에 선다. 릴레이가 멈추고 재회.
   - **밸런싱 북극성:** 승리 = *여러 원정에 걸친 흔적 축적*(한 번의 완벽한 런 아님). 남기기가 엔딩의 열쇠. 돌파 난이도가 정서의 핵심 튜닝.

**제목 의미 세 층:** ① 떠나는 원정대에게 하는 작별 → ② 실은 메타 '나'에게 하는 약속 → ③ (결말) 건너편에서 기다리는 건 내가 거듭 보낸 *모든 원정대*. 작별이 문자 그대로 재회가 된다.

## 5. 게임 흐름 (코어 루프)

```
타이틀
  → [첫 플레이] 오프닝 서사 슬라이드쇼            ← 구현됨 (Opening.gd)
  → 마을 / 시장: 가방 꾸리기(6칸에 물품 골라 담기, 시작 자원 결정) + 시장 NPC 튜토리얼  ← 구현됨 (Loadout.gd)
  → 지도(탑뷰, 양피지): 다음 노드 선택              ← 구현됨 (Map.gd)
      마커가 맵 위를 이동(거리만큼 자원 소모, 이동 중 자잘한 상황 카드)
  → 도착 노드 "단면 탐색"(TWoM): 지점 여러 개 중 "살필 틈"(예산)만 조사  ← 구현됨 (Expedition + SectionRun/SectionArt)
      조사 결과 = 이벤트 카드 / 자원 / 흔적 줍기 / 로프 통과 / 빈손
  → 자원 고갈 or 위협으로 죽음 → 시체·죽은 자리 흔적
      (또는 살아있을 때 "남기기" 1회: 물건 하나 두고 자원만 잃고 계속)
  → 지도 갱신(안개 걷힘·죽은 자리·남긴 물건), 다음 원정             ← 반복 (흔적 누적)
  → 목적지(end) 도달 → 순환 / 재회 엔딩                          ← 구현됨 (GameState.ending_kind, Expedition._show_ending)
```

- **두 레이어:** 계획(지도) ↔ 실행(도착 노드 단면). 이동은 맵 위에서 일어난다(별도 이동 씬 없음).
- **자원 = 수명.** 물·식량·로프·은신처. 걸음마다 닳고(거리 비례), 바닥나면 죽는다. 남기면 그만큼 잃는다.

## 6. 핵심 메커닉 (한 줄씩)

- **자원=수명 / 거리 곡선.** 출발지 근처 풍요, 멀수록 척박(물 소모 거리 비례). `ExpeditionRun.water_cost`.
- **남기기(런당 1회) ↔ 줍기.** 죽기 전(또는 살아서) 물건 하나를 노드에 둔다(자원 -비용). 다음 원정대가 줍는다(유한 uses). `TraceData`, `GameState.pickup_traces_by_node`.
- **차단 로프 = 영구 지형.** 차단에 로프 걸면 그 노드에 ROPE 흔적 → 다음 원정 무료 통과. `Situations.crossed_blockage`.
- **선택 반영 플래그.** choice 의 `sets`(런)/`sets_persist`(영속) → 이후 이벤트 `requires` 를 깬다. 같은 런 연쇄 + 다음 원정 변형.
- **위협 삼각형.** 소모(갈증)·차단·폭풍. 각자 다른 대비 자원(물/로프/은신처)을 요구, 한정된 남김을 두고 경쟁.
- **지도 = 노드 그래프(고정 디자인) + 강한 미지.** 가본 노드만 정체 공개, 갈 수 있는 다음은 "?", 그 너머는 안 보임. `MapGraph.NODES`, `visited_nodes`.

## 7. 현재 구현 상태 (Phase 0)

**됐음:** 코어 루프 전 구간(지도 이동 → 단면 탐색 → 죽음/남기기 → 반복 → 결말), 오프닝 서사, 흔적 남기기·줍기·차단 로프·선택 반영 플래그·거리 곡선·이동 중 상황, 노드 일원화, 양피지 지형 비주얼, 결말 순환/재회 엔딩, 설정창·데이터 초기화·음량 저장, 한글 폰트 임베드.

**아키텍처:** `scripts/core/`(순수 데이터·로직: ExpeditionRun·SectionRun·MapGraph·Situations·TraceData·Threats) ↔ `scripts/ui/`+`scenes/`(렌더·입력) ↔ `GameState.gd`(autoload: 전역 상태·씬 라우팅·세이브). core 는 ui/GameState 미참조.

**남음(backlog):** 마을/시장 **가방 꾸리기 + NPC 튜토리얼**(다음), 결말 순환의 *물리적* 반영(도달점=다음 목표)·재회 임계 밸런싱, 단면 콘텐츠 확충, 폭풍 파티클, 지도 다듬기, **실제 그림 에셋 교체**(오프닝·단면 — 지금은 절차적 1차).

## 8. 열린 지점 (나중에 정할/고칠 것)

- **오프닝 서사 문구** — 현재 5장은 임시(사용자: "약간 별로, 나중에 고침"). `Opening.gd` 의 `SLIDES` 한 곳.
- **중간 서사의 밀도** — 지금은 흔적·이벤트로만. 서울2033식 텍스트 밀도를 어디까지 채울지(맥거핀은 유지).
- **재앙의 정체를 결말에서 얼마나 명시할지** — "가장 멀리 간 원정대"라는 반전을 얼마나 대놓고/암시로.
- **재회 돌파 난이도**(`GameState.REUNION_TRACES`, 임시 8) — 정서 핵심 튜닝, 폰 테스트.
- **가방 꾸리기가 자원=수명에 주는 무게** — 고정 시작 자원을 선택으로 바꾸며 밸런스 재조정.
