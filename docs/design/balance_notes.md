# 밸런스 튜닝 노트 — 내일 이어받기용

> **이 문서 하나로 밸런스 작업을 바로 이어간다.** 사용자가 "밸런스 이어서" 하면 여기부터.
> 도구: `tests/balance_sim.gd`(정량 시뮬), `scripts/ui/DebugOverlay.gd`(실기기 세팅). 실행법은 `00_START_HERE.md` §8.
> 만든 맥락: 2026-07-01 밤 세션(도구 제작 + 첫 발견). 튜닝 자체는 사용자와 진행하기로 미룸.

## 어떻게 작업하나 (워크플로)

1. 손잡이 하나(또는 조합)를 바꾼다 (아래 §손잡이, 파일:줄 명시).
2. `godot --headless --path . -s tests/balance_sim.gd` 실행 → 리포트 비교.
   - 볼 것: **end 도달률**, 정책별 **중앙 leg**, **평균 최종 노드 row**, **사인 분해**(갈증/배고픔), **콘텐츠 커버리지**(0=못 봄).
3. `godot --headless --path . -s tests/core_smoke.gd` 로 회귀 없는지(ALL PASS) 확인.
4. 수치가 코드/기획서 양쪽에 있으면 **같은 커밋에서 둘 다** 갱신(기획서 §4.3 거리 곡선 등).
5. 실기기 체감은 DebugOverlay(자원 가득/노드 점프/God)로 원하는 지점만 띄워 확인.

⚠️ **시뮬 baseline 동기화:** `balance_sim.gd`의 `BASE_START` 는 `GameState.START_RESOURCES`(=Loadout 표준 구성)와 맞춰야 한다. 시작 자원을 바꾸면 둘 다.

## 현재 시뮬 발견 (2026-07-01, 정책당 500판)

- **★ end 도달 0.0% (전 정책·시작 물 28 까지).** 그래프 row 0→7(end)인데 최적(생존탐욕)도 **평균 최종 row 4.5, 중앙 leg 25 에서 갈증사.**
  → **재회 엔딩 + 후반부(row 5~7) 콘텐츠가 현재 밸런스로는 도달 불가.** f1 폭풍의 문·`storm_gate*`·`pool_drank→storm_gate_ill` 체인이 전부 죽은 콘텐츠(커버리지 0).
- **사인 93~98% 갈증, 배고픔 0~2%.** 물이 유일한 제약, 식량 13 은 과잉 → 위협 삼각형이 소모(물) 한 축으로 쏠림.
- **시작 물 스윕**(생존탐욕): 물 12→28 이면 중앙 leg 16→25, 평균 row 2.6→4.5, 갈증사 100%→85%. 물이 곧 도달 거리. (선형적, 손잡이 잘 먹음)

### 왜 도달 못 하나 (대략 계산)
end(row 7)은 엣지 7개 × `EDGE_LEN` 5 = **최소 ~35 걸음**. `water_cost = 1 + leg/16` 이라 leg 35 에선 3/걸음.
누적 물 소모 ~35걸음 ≈ 55~60. 시작 20 + 캐시 보충(도달분 ~15~20) ≈ 40 → **leg 25 근처에서 바닥.** 약 **+15~20 물 지속력**이 모자란다.

## 후보 방향 (사용자와 결정 — 임의로 안 정함)

1. **후반 완화(추천 1순위):** `DESOLATION_EVERY` 16→22~26. 후반 물 가속을 늦춰 도달 거리를 늘림. 초반 긴장 유지. 상수 1개.
2. **엣지 단축:** `EDGE_LEN` 5→4. 총 걸음 35→28. 도달 쉬워지나 이동 중 상황·거리감 감소.
3. **그래프 축소:** row 7→5~6. "덜 긴 여정". 맵/콘텐츠 재배치 필요(큼).
4. **캐시 물 증량(후반 노드):** row 4~6 노드에 물 보충 늘림. 긴장 유지 + 라우팅 보상. 콘텐츠 작업.
5. **식량을 진짜 2번째 축으로:** 식량↓(가방/START) 또는 `FOOD_EVERY` 2→1. 갈증 독점 완화(사인 다양화).

### 설계 의도 (놓치지 말 것)
- end/재회는 **어렵되 가능**해야 한다(지금은 불가능=문제). 목표는 "높은 완주율"이 아니라 **여러 원정 축적 + 좋은 런이면 닿는" 정도**(단일 런 end 도달 ~5~15%면 충분할 수 있음).
- 재회는 end 도달 **+ 흔적 8개 축적 + 무사 도달** 셋 다 필요 → 단일 런 시뮬의 end 도달률은 필요조건일 뿐. 완전한 재회 경로는 **다중 원정 시뮬(2단계, 미구현)**로 봐야 정확.
- 거리 = 척박함의 기울기(기획서 §4.3)는 유지 — 후반이 가혹한 건 의도. "도달 불가"만 고치는 것.

## 추천 첫 수 (제안, 확정 아님)
`DESOLATION_EVERY` 16→22 + `EDGE_LEN` 5→4 로 시작 → 시뮬 스윕으로 "생존탐욕이 end 를 10~30%, 무모는 거의 0%" 나오는 지점을 찾는다.
그 뒤 식량을 살짝 줄여(예: 가방 식+6→+4 또는 FOOD_EVERY 2→1) 사인이 갈증 70/배고픔 20/위협 10 쯤 되게. 매 변경마다 `balance_sim` 재실행 비교.
