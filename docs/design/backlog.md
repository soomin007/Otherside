## 데스크톱 (구현 — 귀한 시간)

- [ ] **글씨 흐림/깨짐 해결.** 시크릿 창에서 한글은 뜨나 약간 깨져 보임(해상도/스케일 추정). 후보 원인:
      stretch(canvas_items+expand) 비정수 배율, `rendering/.../default_texture_filter=0`(Nearest)이 폰트 글리프 샘플링에 영향,
      폰트 oversampling 또는 MSDF 임포트 옵션. 비주얼 작업과 함께 손보면 좋음.
- [ ] **그래픽/비주얼 전면 교체.** 현재 플레이스홀더 UI가 EoY와 흡사 — 고유 비주얼 디렉션 필요.
      모래폭풍/원정/흔적 정서에 맞는 팔레트·타이포·레이아웃. (`scripts/ui/*` 코드 UI를 테마/씬으로 분리하며 진행)
- [ ] **★ 선택 반영 일반화 (핵심).** "이전 선택이 이후에 바뀌어 나온다"가 게임의 제일 중요한 축(기획서 §1, 서울 2033·Reigns).
      지금은 랜드마크 재방문 변형(`landmark_log`/`requires`)만 — leg 종속. 일반화 방향: 명명 플래그(선택 → set),
      같은 런 내 연쇄(앞 선택이 뒤 일반 상황·랜드마크를 바꿈), 누적 상태. 이벤트 `requires` 를 플래그 조건으로 확장.
- [ ] **런 길이 확장 + 거리 난이도 곡선.** 현재 ~10턴은 너무 짧다(Reigns = 한 판이 짧지 않게). leg 범위·시작 자원·소모를 조정해 늘린다.
      출발지(마을) 근처는 평화·풍요(보충 많고 위협 드물게), 멀어질수록 척박·고달픔(위협 잦고 보충 귀하게). 거리(leg)에 따른 스케일링.
- [ ] **페이싱 튜닝 (폰 테스트).** 일반 상황 2~4걸음 랜덤(`ExpeditionRun.GAP_MIN/MAX`), 랜드마크 고정 leg. 폰으로 간격·효과 수치를 체감 조절.
- [ ] **랜드마크 이벤트 콘텐츠 확충.** 시스템(이벤트 풀 + 과거선택 변형)은 구현됨(`Situations.LANDMARKS[].events`, `requires`/`choice_id`).
      각 랜드마크에 이벤트·변형을 데이터로 더 추가(현재 cache 3곳은 이벤트 2 + 변형 1, 차단/폭풍은 1개씩). 차단/폭풍 랜드마크도 사건 다양화 여지.
- [ ] **남김 확장.** "남김 한 번"은 본구현됨(자발적 종료 → 자원 1종/시체 + 태그 선택, `Expedition` 남김 패널). 고갈사는 시체만.
      남은 것: *어디에* 남길지(위치 선택 = 전달 확실성 vs 폭풍 위험)와 자원=수명 밸런스 튜닝.
- [ ] **다음 런에서 흔적 줍기 — 효과.** 과거 런의 흔적은 이미 횡스크롤에 점으로 렌더됨(self-async). 남은 것:
      흔적을 *집어* 위협을 완화하는 상호작용(물통 → 물 보충 등). (`GameState.loaded_traces()`)
- [ ] **지도 레이어 본구현.** 안개 걷힘 / 죽은 자리 표식 / 흔적 점 누적 렌더링. (`map.tscn`)
- [ ] **폭풍 CPUParticles2D 3층 연출 + 성능 테스트.** 폭풍 메커니즘은 본구현됨(구간형+예고, 은신처/강행).
      반투명 그라데이션 띠(1층)는 `Expedition._draw_storm` 에 들어감. 남은 것: 중경 스프라이트 몇 장(2층) + 전경 CPUParticles2D 소량(3층).
      데스크톱+모바일 성능 확인, 셰이더/GPUParticles 금지.
- [ ] **설정 확장.** 설정창·데이터 초기화는 구현됨(`SettingsPanel.gd`, 타이틀 오버레이 + 확인 다이얼로그).
      남은 것: 음량은 지금 master bus 에 즉시 반영만 하고 저장 안 됨 → 세이브/복원 연결, 접근성 옵션(글자 크기 등) 추가.
