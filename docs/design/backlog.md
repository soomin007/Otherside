      모래폭풍/원정/흔적 정서에 맞는 팔레트·타이포·레이아웃. (`scripts/ui/*` 코드 UI를 테마/씬으로 분리하며 진행)

      폰으로 수치 체감 조절: 시작 자원·`DESOLATION_EVERY`(16)·일반 상황 간격(`GAP_MIN/MAX`)·효과 수치. 후반 전용 가혹 상황(데이터)도 여지.
- [ ] **랜드마크/선택 반영 콘텐츠 확충.** 시스템 완비(이벤트 풀 + 플래그 `sets`/`sets_persist`/`requires`, 같은 런 연쇄 + 영속).
      데이터로 더: 랜드마크별 이벤트(현재 cache 3곳 이벤트 2 + 변형 1, 차단/폭풍 1개씩), 같은 런 연쇄·누적 상태 스토리 분기, 일반 상황(CATALOG) `requires` 연쇄.
- [ ] **남김 밸런스 튜닝.** "남김 한 번" 본구현 완료(런당 1회 "남기기" → 물건 1종+태그를 그 자리에 두고 *자원 -비용*만 잃고 **계속 전진**, 죽음과 분리). **자발적 죽음("여기서 끝") 제거 — 모든 죽음 비자발적(고갈/위협), 시체만.** 비용=줍기 값 대칭(물4·식3·은1·로프1), 생존 자원은 죽지 않을 만큼만. 남긴 자원=줍기 가능(uses).
      남은 것: 비용·줍기 값·uses 수치 감각(폰 테스트). 늦은 지식 전달은 게임적 허용(설계, 기획서 §3) — 토큰 안 늘림("하나만" 유지).
- [ ] **★ 지도/횡스크롤 재구조 (StS 맵 + TWoM 단면, 진행 중).** 완료: 그래프+렌더+연동, **맵 정비**(클릭 가능 노드 밝게 강조 + 안개(방문+인접만) + `visited_nodes` 영속 추적).
      남은 것(사용자 확정 방향): ① **막대(걷기) 폐기 → 이동 모델**: 맵에서 노드 이동 = 거리만큼 자원 소모 + 이동 중 자잘한 상황(소모 결정).
      ② **랜드마크 단면 탐색 씬(TWoM)**: 도착 시 그 장소 단면을 둘러보며 자원 찾기·선택(단면 내 상호작용 엔진 — 가장 큰 작업). ③ 흔적 줍기·차단 영구화·죽음 표식의 노드화(지금 leg 기반이라 잠시 빠짐). ④ `Situations.LANDMARKS`(leg) 폐기 → 노드 events 일원화. ⑤ 목적지(end) 도달 처리(승리 미정).
- [ ] **지도 비주얼 다듬기.** 노드 칩 스타일·팔레트, 긴 그래프 카메라/스크롤, 이름 겹침 정리. (그래픽 전면 교체와 함께)

      반투명 그라데이션 띠(1층)는 `Expedition._draw_storm` 에 들어감. 남은 것: 중경 스프라이트 몇 장(2층) + 전경 CPUParticles2D 소량(3층).
