## 데스크톱 (구현 — 귀한 시간)

- [ ] **글씨 흐림/깨짐 해결.** 시크릿 창에서 한글은 뜨나 약간 깨져 보임(해상도/스케일 추정). 후보 원인:
      stretch(canvas_items+expand) 비정수 배율, `rendering/.../default_texture_filter=0`(Nearest)이 폰트 글리프 샘플링에 영향,
      폰트 oversampling 또는 MSDF 임포트 옵션. 비주얼 작업과 함께 손보면 좋음.
- [ ] **그래픽/비주얼 전면 교체.** 현재 플레이스홀더 UI가 EoY와 흡사 — 고유 비주얼 디렉션 필요.
      모래폭풍/원정/흔적 정서에 맞는 팔레트·타이포·레이아웃. (`scripts/ui/*` 코드 UI를 테마/씬으로 분리하며 진행)
- [ ] **페이싱·밸런스 튜닝 (폰 테스트).** 런 길이·거리 곡선 구현됨(START 물20·식량13, `water_cost` 거리 비례, 랜드마크 4~28 풍요→척박, ~24걸음).
      폰으로 수치 체감 조절: 시작 자원·`DESOLATION_EVERY`(16)·일반 상황 간격(`GAP_MIN/MAX`)·효과 수치. 후반 전용 가혹 상황(데이터)도 여지.
- [ ] **랜드마크/선택 반영 콘텐츠 확충.** 시스템 완비(이벤트 풀 + 플래그 `sets`/`sets_persist`/`requires`, 같은 런 연쇄 + 영속).
      데이터로 더: 랜드마크별 이벤트(현재 cache 3곳 이벤트 2 + 변형 1, 차단/폭풍 1개씩), 같은 런 연쇄·누적 상태 스토리 분기, 일반 상황(CATALOG) `requires` 연쇄.
- [ ] **남김 밸런스 튜닝.** "남김 한 번" 본구현 완료(자발적 종료 → 자원 1종/시체 + 태그, 위치는 선택한 그 자리 고정 — 위치 선택 폐기, 사용자 확정).
      남은 것: 자원=수명 트레이드오프 수치 감각(무엇을 남기면 얼마를 잃나, 폰 테스트).
- [ ] **지도 비주얼 다듬기.** 2D 지형도 본구현됨(`Map.gd` — leg→곡선, 안개, 죽은자리·흔적·로프·랜드마크 마커).
      남은 것: 지형 텍스처·팔레트, 긴 경로 카메라/스크롤, 마커 겹침 정리. (그래픽 전면 교체와 함께)
- [ ] **폭풍 CPUParticles2D 3층 연출 + 성능 테스트.** 폭풍 메커니즘은 본구현됨(구간형+예고, 은신처/강행).
      반투명 그라데이션 띠(1층)는 `Expedition._draw_storm` 에 들어감. 남은 것: 중경 스프라이트 몇 장(2층) + 전경 CPUParticles2D 소량(3층).
      데스크톱+모바일 성능 확인, 셰이더/GPUParticles 금지.
- [ ] **설정 확장.** 설정창·데이터 초기화는 구현됨(`SettingsPanel.gd`, 타이틀 오버레이 + 확인 다이얼로그).
