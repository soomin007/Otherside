# 피드백 설문 (구글 폼) v0.1 — 출시 후 소통 창구

EoY 때와 같은 패턴. 폼은 사용자(구글 계정)가 직접 개설하고, 여기 초안을 복사해 붙인다.
개설 후 forms.gle 단축 URL 을 받으면 아래 "URL 기입처" 두 곳에 반영한다.

## URL 기입처 (개설 후)

- `scripts/GameState.gd` 의 `FEEDBACK_URL` 상수. 기입하는 순간 타이틀 메뉴에 "의견 보내기" 항목이 나타난다(비어 있으면 숨김).
- 캐러셀 10번(CTA) 장. 아래 "포스터 반영" 참고.

## 폼 설정 체크리스트 (EoY 교훈)

- [ ] 설정 → 응답 → **"로그인 필요" 끄기** (안 끄면 익명 응답이 막혀 응답률이 뚝 떨어진다)
- [ ] **이메일 수집 안 함** (익명 유지)
- [ ] 응답 횟수 제한 없음 (여러 번 플레이하고 또 보낼 수 있게)
- [ ] 보내기 → 링크 → **URL 단축** 체크 (forms.gle 짧은 주소)

## 폼 제목·설명 (복붙용)

제목:

> See you on the other side — 플레이 의견

설명:

> 플레이해 주셔서 감사합니다.
> 1분이면 충분합니다. 뒤쪽 서술형 문항은 건너뛰셔도 됩니다.
> 응답은 익명으로 수집되며, 게임을 다듬는 데 소중히 쓰겠습니다.

## 문항 (복붙용)

응답률을 위해 9문항, 필수는 앞 6개(전부 객관식)만. 서술형 3개는 선택.

1. **게임을 얼마나 플레이해 보셨나요?** (객관식, 필수)
   - 1~2번 플레이해 봤다
   - 여러 번 플레이했다
   - 엔딩까지 봤다
   - 엔딩을 본 뒤에도 계속 플레이하고 있다
2. **어떤 기기로 플레이하셨나요?** (객관식, 필수)
   - 스마트폰
   - 컴퓨터
   - 둘 다
3. **게임은 전체적으로 어떠셨나요?** (선형 배율 1~5, 필수. 1=아쉬웠다, 5=아주 재미있었다)
4. **원정 한 번의 길이는 어떻게 느끼셨나요?** (객관식, 필수)
   - 짧은 편이었다
   - 적당했다
   - 조금 긴 편이었다
5. **난이도는 어떻게 느끼셨나요?** (객관식, 필수)
   - 쉬운 편이었다
   - 적당했다
   - 어려운 편이었다
   - 원정마다 달랐다
6. **이전 원정대가 남긴 물건이나 글은 도움이 되었나요?** (객관식, 필수)
   - 도움이 되었고, 기억에도 남았다
   - 도움이 되었다
   - 크게 도움이 되지는 않았다
   - 잘 모르겠다
7. **가장 기억에 남는 순간이 있었다면 알려 주세요.** (장문형, 선택)
8. **불편했거나 헷갈렸던 부분이 있었다면 알려 주세요.** (장문형, 선택)
9. **그 밖에 하고 싶으신 이야기가 있다면 자유롭게 적어 주세요.** (장문형, 선택)

- 6번은 핵심 기둥(선택 반영) 체감 측정. 4번은 런 길이 기둥, 5번은 밸런스 2차 튜닝(`balance_notes.md` 기준선) 입력.
- 문항을 더 넣고 싶어도 참는다. 길어질수록 응답이 준다(EoY 때 짧아서 잘 굴러갔다).

## 포스터 반영 (캐러셀 10번 CTA 장)

- 기존 확정 문구("프로필 링크에서 바로 플레이" + URL)는 그대로 두고, 그 아래 작게 한 줄 + 설문 URL 추가를 권장:

> 플레이하셨다면 짧은 의견 한 줄이 큰 힘이 됩니다
> forms.gle/XXXXXXX

- URL 폰트는 확정사항 14번대로 Cinzel. 색 강조를 쓴다면 모래색 #D6B278 한 가지만.
- QR 은 화면(인스타)에선 자기 폰으로 못 찍으므로 안 넣는다. 인쇄 포스터를 만들 때만 QR 추가(URL 확정 후 생성 요청하면 만들어 드림).

## 인게임 배선 (완료)

- `GameState.FEEDBACK_URL` + `open_feedback()` — 웹은 JavaScriptBridge 로 새 탭, 데스크톱은 OS.shell_open. 버튼 pressed 컨텍스트에서만 호출(팝업 차단 회피).
- 타이틀(`Main.gd`) 메뉴 맨 아래 "의견 보내기" (22px, 설정과 같은 급). URL 이 비어 있으면 항목을 만들지 않는다.

## 응답 활용

- 응답이 쌓이면 4·5번 분포로 밸런스 2차(기준선 end 19.0%)를 조정하고, 6번으로 흔적 체감을 점검한다.
- 주관식은 `docs/design/backlog.md` 후보로 옮겨 삭제 방지.
