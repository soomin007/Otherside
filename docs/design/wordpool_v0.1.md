# 단어 풀 (Word Pool) — v0.1

> See you on the other side — 흔적 태그용 제약 단어 목록
> 원칙: 유한·빈약·조합형. 물건이 의미의 절반을 말하므로 태그는 짧게.
> 최종 갱신: 2026-06-29

---

## 설계 원칙

- **유한하게.** 시작은 ~30개 미만. 적을수록 강하다. 부족함이 무기 — 플레이어가 고르느라 고민하고, 읽는 사람이 행간을 메운다.
- **조합형.** 단어 하나로도 의미가 서고, 둘을 붙이면 새 의미가 난다. 물건이 이미 맥락을 주므로(물통 = 갈증, 로프 = 차단) 태그는 한두 개만 얹는다.
- **확장은 사후.** 빌드 후 폰으로 굴려보며 "하고 싶은 말인데 단어가 없네" 하는 순간에만 *그 단어만* 추가. 미리 채우지 않는다.
- **거짓 태그 없음 (본작).** 혼자 플레이(self-async)라 속일 적대적 타인이 없다 — 흔적을 남긴 이전 원정대도 결국 플레이어 자신의 세계다. 대신 이전 원정대가 *틀릴* 수는 있다(`안전`이라 적었는데 아니었던 실수). 거짓말이 아니라 오인 — 흔적을 온전히 믿지 못하는 긴장이 여기서 나온다.

## 단어 목록 (총 27)

### 방향 / 공간 (9)
`앞` · `뒤` · `위` · `아래` · `여기` · `건너` · `돌아가` · `못` · `가`

> `못`은 독립 부정 연산자. 다른 단어에 붙어 확장: `못`+`가`, `못`+`건너`, `못`+`믿다` 등.

### 경고 / 위협 (9)
`조심` · `위험` · `갈증` · `추위` · `폭풍` · `함정` · `없다` · `끝` · `안전`

> 위협 삼각형(소모/차단/폭풍)과 직결. 미래의 위협을 *예고*하는 핵심 카테고리.

### 시간 (6)
`곧` · `멀다` · `늦다` · `아직` · `다시` · `마지막`

> 감정을 직접 말하지 않으면서 정서를 만든다. `늦다`는 슬픔을 한 글자도 안 쓰고 슬프다.

### 인사 (5)
`또` · `봐` · `간다` · `미안` · `고맙다`

> `또`+`봐` = 제목 "See you on the other side"의 게임 내 번역. 정보 0, 정서 100.
> `봐`도 독립 사용 가능: `봐`+`앞`("앞을 봐") 등.

## 조합 예시

물건이 절반을 말하고, 태그가 나머지를 얹는다.

| 흔적 | 태그 | 읽히는 의미 |
|---|---|---|
| 물통 | `앞` `없다` | 앞에 물 없다 (경고) |
| 로프 | `건너` `조심` | 여기로 건너되 조심 |
| 시체 자리 | `끝` `미안` | 난 여기서 끝났어, 미안 (정보 0, 정서 100) |
| 은신처 | `폭풍` `곧` | 폭풍 곧 온다, 여기 숨어 |
| 빈 표식 | `돌아가` `늦다` | 돌아가, 너무 늦었어 |
| 빈 표식 | `또` `봐` | 정보 없이, 그냥 작별 |
| 물통 | `안전` | (틀릴 수 있음 — 이전 원정대의 오인) |

## 확장 후보 (아직 넣지 않음)

빌드 후 필요성이 *증명되면* 추가:
- 메타/신뢰 (`믿다`, `모른다`, `어쩌면`) — 본작 최소화, 둘째 쌍둥이/타 플레이어 흔적에서 살릴 여지
- 수량/정도 (`많다`, `조금`, `깊다`)
- 추가 위협어 — 위협 목록 확정 후 거울로 추가
