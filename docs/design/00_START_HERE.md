## 1. 게임 한 문장

**See you on the other side** (Godot 4.6, 2D, GDScript, 웹 배포). 비동기 로그라이트.
모래폭풍이 세계를 쓸고 지나가 잠잠해질 때마다, 그 틈에 원정대가 재앙을 멈추러 떠나고 거의 다 죽는다. 플레이어는 그 원정대를 **거듭 보내는 총괄자이자 매 원정의 대장 자리**에 앉는다. 모래폭풍이 글씨를 지우는 세계에서, 죽기 전 **단 한 번** 다음 원정대에게 *물건*을 남긴다.
- **중심 질문:** 누군가 결국 닿을 것을 알 때, 미래의 나를 위해 지금의 나는 무엇을 포기하는가.
- **★ 최우선 설계 축:** 선택의 반영 — 한 선택이 플래그를 남기고 같은 런·다음 원정의 이벤트·텍스트를 바꾼다.

## 2. 세계관 (요약)

- 원정대 릴레이 — **폭풍이 여는 주기**. 모래폭풍이 세계를 쓸고 지나가 잠잠해질 때마다 그 틈에 떠난다(간격은 불규칙·긺, "매년" 아님 — 폭풍이 시계다). 거의 다 죽고, 한 번에 닿는 이는 없다. (릴레이 좌표는 Expedition 33·데스 스트랜딩과 공유하나 *주기의 엔진*은 고유의 폭풍 — 표절 회피의 핵.)
- 모래폭풍 = 세계 법칙 → 말(자유 텍스트)은 못 남기고 **물건만** 남긴다 + 로그라이트 리셋의 서사적 근거.
- 재앙의 정체 = **맥거핀**. 플레이 내내 안 밝힌다. 결말에서만 드러난다(§3).

## 3. 전체 서사 아크 (세 마디)

1. **도입 — 오프닝** (구현됨): 세계·원정대·모래폭풍·남기기·정체성을 담담·서늘하게 소개. 재앙 정체는 안 밝힘. 첫 플레이만 자동 재생.
2. **본편 — 반복 원정** (열려 있음): 정해진 스토리 대사 없음. 이야기는 *겪고 남긴 흔적*으로 생긴다(죽은 자리·남긴 물건·로프·재방문 변형). 각본이 아니라 거울.
3. **결말 — 순환과 재회** (구현됨, 사용자 확정):
   - **기본 = 순환(서늘).** 목적지(재앙의 자리)엔 먼저 간 이전 원정대가 서 있다 → 재앙 = *가장 멀리 간 원정대*. 밀어내고 이번 원정대가 그 자리 → 다음 원정대가 이곳으로 온다(이번이 다음의 재앙). 릴레이는 멈추지 않는다. **세계가 순환을 기억한다(2026-07-15 구현):** 두 번째+ 순환 재도달 슬라이드는 "그 재앙"(직전 순환 원정)의 이름을 호명, 첫 순환 후 지도 end 는 "???" 대신 "그들이 선 자리"+서 있는 사람, 막간은 "그들은 그 자리에 남았다". 그래프 변화(도달점 이동)는 서사 모순으로 폐기, 밀려난 이들 행방은 침묵(기획서 §3).
   - **출구 = 재회(따뜻, 진짜 엔딩).** 도달 자체는 순환과 같다(살아서 닿음) — 가르는 건 세 축, 전부 사람(2026-07-10 확정. 옛 "남긴 흔적 ≥ 4" 축은 폐기): ① **기린 죽은 자리 ≥ 2**(`REUNION_MOURN`, 추모=죽은 자리에 표식 남기기·런당 1회의 남기기 사용) ② **낙오자 ≥ 2를 거두어 이번 런에 데리고 닿기**(`REUNION_RESCUES`. 낙오자=유령 씨앗 b1·c1·d2 + 과거 런의 대원 손실 자리. 거두기=물 -2, 지나치면 남는다, 데려가다 죽으면 잃는다. 지도에 웅크린 사람 마커. 손실 출신은 카드가 출처(원정 이름·사연)를 말하고 거두면 후속 한 박자(then), 잃으면 전용 문구 — 2026-07-13) ③ **온전한 도달 = 행렬 손실 0**(원정대=대장+대원 4의 행렬(연출 파티, 자원 모델 불변), 위험한 순간(도구 없이 위기에 당함·물/식량 바닥 스침)마다 대원이 스러진다. `ExpeditionRun.party_lost`. 구조는 손실을 상쇄 안 함. 대원 죽음은 기림 자리를 안 남기되 그 자리가 낙오자가 된다). 채우고 닿으면 먼저 간 모든 원정대와 함께 건너편에. 릴레이 멈춤.
   - 승리 = 한 번의 완벽한 런이 아니라 **여러 원정에 걸친 흔적 축적**. 남기기가 엔딩의 열쇠.
- **제목 세 층:** ① 떠나는 원정대에게 하는 작별 → ② 실은 메타 '나'(총괄자)에게 하는 약속 → ③ (결말) 건너편에서 기다리는 건 내가 거듭 보낸 모든 원정대. 작별이 재회가 된다.

## 4. 게임 흐름 (현재 실제 코어 루프)

```
타이틀(Main.gd)
  → [첫 플레이만] 오프닝 서사(Opening.gd) →
  → 마을 · 가방 꾸리기(Loadout.gd): 6칸 가방에 물품 담기 → 시작 자원 결정 + 첫 원정 시장 NPC 튜토리얼(무게 설명 포함)
  → [첫 원정만] 마을 단면 탐색 연습(VillageIntro.gd): 안전·무보상, 조사 예산·지점 살피기 익히기 → 지도
  → 지도(Map.gd, 양피지 노드 그래프): 갈 노드 선택(강한 미지 — 가봐야 안다)
  → 맵 위에서 마커가 그 노드로 이동(Map._process): 거리만큼 자원 소모 + 이동 중 자잘한 상황 카드
  → 도착 노드 "단면 탐색"(Expedition.gd + SectionRun/SectionArt): 여러 지점 중 제한된 조사 횟수(예산 2)만 쓴다
       조사 결과 = 이벤트 카드 / 자원 / 흔적 줍기 / 로프 통과 / 빈손
  → 자원 고갈·위협으로 죽음(시체·죽은 자리 흔적) 또는 살아서 "남기기" 1회(물건 두고 자원만 잃고 계속)
  → 지도로 복귀(안개 걷힘·노드 흔적 마커) → 다음 노드 …
  → 목적지(end) 도달 → 순환/재회 엔딩(GameState.ending_kind → Expedition._show_ending)
  → [원정 끝: 죽음 또는 순환] **폭풍 막간**(scenes/interlude.tscn — 지도를 폭풍이 쓸고 지나감·흔적 일부 묻힘·다음 원정대 지명) → 마을(Loadout)부터 다음 원정
```
두 레이어: **계획(지도) ↔ 실행(도착 노드 단면)**. 이동은 맵 위에서 일어난다. **별도 횡스크롤 이동 씬은 없다.**

## 5. 현재 구현 상태 (파일별 — 뭐가 되어 있나)

**core (`scripts/core/`, 순수 데이터·로직, GameState/ui 미참조):**
- `MapGraph.gd` — 고정 노드 그래프(`NODES`, n0 마을 → … → end). 각 노드 `{kind,name,row,col,next,events,spots?}`. 콘텐츠의 유일한 집.
- `ExpeditionRun.gd` — 한 원정 상태·로직. 엣지 전진(`step`), 도착 카드 계산(`arrival_event`: 로프 통과>줍기>이벤트), `raise_situation`, 자원 소모·죽음, 남기기(`do_leave`), 흔적/차단은 **node_id 키**.
- `SectionRun.gd` — 도착 노드 단면 탐색(주요 지점=arrival_event + 보조 지점=node.spots, 조사 횟수 예산, `probe`→결과 디스크립터, `probed_count`). 순수(-s 검증 가능).
- `Situations.gd` — `CATALOG`(이동 중 상황), `pick_event`(노드 events), `pick_crisis`(**위기 순간 전용 풀** — 위기는 일반 회전에 안 섞인다, 2026-07-12), `crossed_blockage`, `pickup_trace`, `can_choose`. 선택지 `then` = 후속 장면 체인(같은 걸음에서 두 번째 카드 — 저작 규칙은 기획서 §4.2·헤더의 **대가 문법**). **`LANDMARKS`는 폐기됨(⑤).**
- `TraceData.gd` — 흔적(`object_kind`, **`node_id`**, tags, uses). `Threats.gd` — 위협 종류.
- `Feats.gd` — 공훈(업적) 정의·판정(순수). **직능은 공훈 보상으로 해금**(2026-07-11 확정): 첫 원정은 평범한 대장 고정, 이룬 일이 마을에 새 직능을 부른다(갈증사 2번 → 물지기 등, 기획서 §4.5). 통계·해금은 `GameState.feat_stats`/`feats_unlocked`(영속), 표시는 일지 "마을" 챕터(펼침 넘김 — 사람들|이룬 일). **기록형 공훈 4종**(끝까지 간 원정·아무도 잃지 않은 원정·모든 길·재회 — 직능 없음, 달성 전 비노출)과 **해금 내력 한 줄(done)**·해금 연출 모달(Loadout, 새 얼굴 인물 등장)은 2026-07-13.

  새 모달·오버레이도 pause 또는 진행 게이트를 명시적으로 정한다(known_issues "이동 중 설정" 항목).

## 7. 핵심 메커닉 (한 줄씩)

- **자원 = 수명.** 물·식량·로프·장막. 걸음마다 닳고(거리 비례) 바닥나면 죽는다. 남기면 그만큼 잃는다.
- **가방 꾸리기.** 매 원정 출발 전 마을에서 6칸 가방에 물품을 골라 담아 시작 자원을 정한다(고정값 아님).
- **무게 대칭 사다리(2026-07-17).** 무게 12 초과 4마다 걸음당 물 +1, 미만 4마다 -1(걸음당 물 바닥 1 — 먼 길에서 실효). 표준 가방 15는 무변동. 기획서 §4.6.
- **남기기(런당 1회) ↔ 줍기.** 물건 하나를 **도착한 노드(node_id)**에 두고 자원만 잃고 계속. 다음 원정대가 줍는다(유한 uses).
- **차단 로프 = 영구 지형.** 차단 노드에 로프 걸면 다음 원정 무료 통과.
- **선택 반영 플래그.** `sets`(런)/`sets_persist`(영속) → 이후 이벤트 `requires`. 같은 런 연쇄 + 다음 원정 변형.
- **위협 삼각형.** 소모·차단·폭풍. 각자 다른 대비 자원 요구.
- **위기 순간(2026-07-12).** 도구 위기는 일반 카드에 안 섞인다 — 엣지마다 위기 순간 확률(`CRISIS_BASE+RAMP×진행도`), 지형 일관, 마지막 두 엣지는 2연속. 바닥 스침 임계 1(`CLOSE_CALL_AT`)·거리 가속 32(`DESOLATION_EVERY`).
- **지도 = 고정 노드 그래프 + 강한 미지 + 뷰 카메라.** 가본 노드만 정체 공개, 다음은 "?". 뷰는 **가본 만큼만 조여서**(줌 상한 1.6) 새 노드가 열릴 때마다 지도가 넓어진다(2026-07-12).
- **직능 = 공훈 해금.** 처음엔 평범한 대장뿐. 공훈(멀리 가기·무거운 짐·갈증사·굶주림사·세 번 남김)을 이루면 마을에 새 직능이 온다. 실패도 자산("죽음 = 정찰"과 한 몸).

## 9. ⚠️ 자주 오해하는 것 (반드시 확인)

1. **정체성:** 플레이어는 "과거의 나"를 따라가는 게 *아니다*. **원정대 총괄자 + 매 원정의 대장 역**이고 매 원정은 *다른 사람*이 간다. 흔적의 in-world 주체 = 이전/다음 원정대. 제목의 '나'는 **메타 층위(총괄자 자리)만**. (lineage 자기자신으로 쓰면 틀림.)
2. **이동은 맵 위에서.** "횡스크롤로 막대가 걷는다"는 **옛 모델(폐기)**. 지금은 지도 노드 그래프에서 마커가 이동하고, 도착하면 그 노드의 *단면 탐색*이 뜬다. 옛 문서의 "횡스크롤 단면으로 전진"·"leg 단위" 서술은 낡은 것.
3. **흔적 위치 = `node_id`.** 예전엔 `leg`(걸음)로 키잉했으나 ④에서 **노드 키**로 전환됨. `TraceData.node_id` 가 위치의 진실(leg 는 표시·정렬용).
4. **남김 위치 = 선택한 그 자리 고정.** "어디에 남길지" 선택은 **폐기됨**(사용자 확정). 위치 UI 만들지 말 것.
5. **재앙 = 맥거핀.** 플레이 중엔 절대 정체를 안 밝힌다. **결말에서만** "가장 멀리 간 원정대"로 드러난다. 중간에 재앙을 설명·형상화하지 말 것.
6. **`Situations.LANDMARKS` 는 없다(⑤ 폐기).** 콘텐츠는 `MapGraph.NODES[].events`(도착)·`Situations.CATALOG`(이동 중)에만. 옛 leg 기반 LANDMARKS 를 되살리지 말 것.
7. **자발적 죽음("여기서 끝") 없음.** 모든 죽음은 비자발적(고갈·위협). 남기기는 죽음과 분리된 별개 행동(런당 1회, 계속 전진).
8. **세션 로그 번호가 뒤죽박죽인 이유:** 여러 세션이 **병렬로** 돌아서다(각 세션이 독립 번호를 붙임). 날짜 파일 안에서 시간순이 아닐 수 있다 — 혼동 말 것. 현재 상태의 진실은 *이 문서 + 코드*지 세션 로그 순서가 아니다.

9. **b2(갈라진 바닥)에 도착 이벤트가 없는 건 버그가 아니다(2026-07-14 사용자 확정).** 유령 씨앗 로프가 세계 시작부터 걸려 있어 도착은 항상 `crossed_blockage`(무료 통과) — 데스 스트랜딩 NPC 사다리처럼 "남긴 물건의 영구 가치"를 첫 원정부터 보여주는 자리. b2 에 이벤트를 되살리지 말 것(스스로 로프 거는 경험은 e1 몫). 이 확정으로 시뮬 기준선도 이동함(balance_notes 헤더).

10. **재회 = 남김(≥4) + 기림(≥2). 죽음 자체는 카운트 0.** `player_trace_count`는 `traces`의 비-seed 항목만 센다(유령 제외) — 죽음은 `deaths` 배열이라 시체가 *자동으로* 재회에 기여하는 일은 없다(외부 공략이 "시체도 카운트"로 착각했던 지점, 2026-07-09 임계 8→4 + 정정). 대신 시체·죽은 자리는 **기림(추모)의 대상**이다(2026-07-09 확정): 죽은 자리에 표식(MARK)을 남기면(`BequeathPanel` 추모, 자원 무료·남기기 토큰 사용) `mourned_nodes`에 쌓이고, `REUNION_MOURN`(2) 이상 기려야 재회가 열린다. 즉 죽음은 *기다리는* 쪽 — 다음 원정대가 기려줄 때 비로소 재회의 문이 된다.
