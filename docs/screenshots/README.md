## UI 어휘 요약 (디자이너용 빠른 참고)

- **팔레트:** 밤하늘 남색 배경 `#0C0D18` + 세피아/모래 베이지 액센트 + 양피지 `#D1BC91`. 서늘·건조·낡은 톤.
- **컴포넌트:** 어두운 반투명 **카드 모달**, 둥근 **필 버튼**(큰 터치 타깃), 상단 반투명 **HUD 바**, 드롭다운, 슬라이더.
- **타이포:** 제목 Cinzel(라틴), 본문 마루부리(한글), 지도 지명은 붓글씨. 장식 유니코드는 폰트에 없어 회피(아이콘은 절차적 draw).
- **제약:** 웹(GL Compatibility) + 터치 우선 → 셰이더/GPUParticles 없음, 버튼 큼직(~56px+).
