## 결정 사항
- 새 spot(단면 지점)은 추가하지 않음 — 아트 좌표 검증(2비율 스크린샷)까지 필요해 이번 범위에선
  이벤트·then 위주. spot 확충은 별도 세션에서.
- d2 영속 플래그는 "사체 묻기 → 다음 원정 물이 맑아짐"으로 (사용자 승인). 맑아진 뒤엔 도착
  카드가 pool_cleared_spring 고정(pick_event matched 우선) — 독 카드가 안 뜨는 게 서사적으로 맞고,
  pool_drank 체인은 이동 카드 murky_spring으로 여전히 열린다.
- e1 신규 2장의 강행 대가(3~4)는 기존(5)보다 헐하게 — 본문이 예고(옛 문·손잡이 로프). 노드 풀 안
  대가 편차는 기존 패턴(d1 등)과 동일.
- end 도달률 14.6→11.6%는 기준선 이동으로 안 봄 — 같은 실행 [3]★가 15.4%로 섹션 간 시드 편차
  (±3~4%p)가 더 크다. 손잡이 수치는 안 건드림.

## 세션 2 (이어서) — "화면 크기" 개명 + 배낭 하단 줄 배율 겹침 수정 (사용자 폰 제보)

### 요약
사용자 제보 두 건 확인: ① "글자 크기가 아니라 UI 크기 같다" → 맞는 인상(content_scale_factor
= 창 전체 배율). 라벨을 실체에 맞게 "화면 크기"로 개명. ② "배낭 챙기기 화면은 그대로 같아
보인다" → 스크린샷 대조로 규명: 적용은 되는데 디에게틱 사진(탁자·물건)이 cover 로 다시 맞춰져
지배적 그림이 안 변함(16:9 에선 스케일 전후 물리 위치가 정확히 일치). 대조 중 진짜 버그 발견:
120% 에서 하단 가방 줄이 기본 채비·떠난다와 겹침 → 수정.
