## 세션 (UI 문구 다듬기 · 버그·밸런스 · 지도 지형화 — map-terrain) — 요약
직능/아이템 설명을 명사형·정량화하고 주머니·로프·은신막 쓰임을 노출. 지도 이동 중 사망 화면 위 튜토리얼 겹침 버그와 초반 열병 즉사를 고침. 배포 간헐 실패를 진단(재실행이 답). 마지막으로 지도를 지형화 — 노드 biome 축 하나로 곡선 경로·경로 따라 지형지물·이동 이벤트 개연성을 함께.

- `Vocations.gd`·`Items.gd`·`Loadout.gd` — 직능/아이템 desc 문장형→명사형+실제 수치(길잡이 물소모 +1 거리 30→42 등), 주머니 도구 설명 라벨(`_tool_desc`), 책상 도구(로프·은신막)는 시작 자원 대신 쓰임 표시.

## 결정 사항
- **biome은 kind와 직교하는 단일 축.** 곡선·지형지물·개연성 셋이 노드 biome 하나를 공유(엣지 A→B 성격 = 도착 노드 biome). 따로 만들면 두 번 손대니 함께.
- **지형지물은 노드 위가 아니라 엣지 곡선 따라.** 노드 아이콘이 이미 지형을 강하게 표현(art-map-icons 산출물)해 노드 위 잉크는 중복 → 경로 따라 옅게(강 양안·산 능선·폭풍 흩날림) 그려 "강을 따라가고 산을 돌아간다"를 시각화(스크린샷 보고 사용자가 이 방향 선택).
- **개연성은 가중(완전 고정 아님).** 지형 맞는 이벤트 ×3, universal 항상, 안 맞는 지형 전용 배제. 같은 풀 분포만 기울여 밸런스 안전.
- **배포 간헐 실패 = 재실행이 답**(코드 무관, GitHub Pages 일시 장애). `gh run rerun --failed`. known_issues에 큐 경합과의 감별법 기록.
