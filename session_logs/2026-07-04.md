## 세션 2 (아트 에셋 배선 + 지도 세로 개편) — 요약
지도 발자국을 실시간으로·마커를 느리게. 지형지물을 절차적("작대기")에서 **원정대 손스케치 에셋**으로 전환(프롬프트+배선). 사용자가 뽑아 넣은 아이템 8종·지형 낙서 4종·메모 3종을 리네임·투명변환·배선. 마지막으로 지도를 화면 fit → **큰 세로 캔버스 + 스크롤**로 개편(아이콘 크게·양피지 비율 복원·곡선 곡률 확대·지형지물 경로 밖).

## 주요 변경 (세션 2)
- `scripts/ui/Map.gd` — 발자국 실시간(마커 지나온 만큼, `_draw_footprints upto`), `STEP_INTERVAL` 0.5→0.65, 지형지물 손스케치 배선(`SKETCH_PATHS`), **세로 큰 캔버스**(`_map_area`·`_node_screen`·`_scroll_y` 드래그/휠 스크롤·상하 가림 띠), 배경 원본비율 세로 타일(테두리·나침반 뺀 중앙 결), 곡선 amp 2~2.5배, 지형지물 chord 중간(경로가 우회).
- `scripts/ui/ItemIcon.gd` 배선 확인 + `assets/arts/transparent/30~37` (아이템 8종: 물통~정화천).
- `assets/arts/transparent/40~46` (지도 손스케치 7종: 강/산/사구/폭풍/해골/경고/화살표).
- `docs/design/art_prompts.md` §12(손스케치 7종 프롬프트) + 진행표 30~46 ✅.

## 결정 사항 (세션 2)
- **지형지물 = 원정대 손스케치 에셋**(절차적 폐기). 방문 구간에 나타남 = 세계관(안개 걷힘). 세피아 펜이 아이콘·양피지 톤과 일치.
- **지도 = 세로 큰 캔버스 + 스크롤**(양피지 원본 비율·아이콘 크게·터치 우선). `_is_landscape` 반응형 폐기.
- 배경 타일: 테두리·나침반을 crop한 중앙 결만 세로 반복(장식 안 겹치게).
- **남기기 "버그"는 오해** — 이미 남긴(`bequeathed`) 상태라 "남겼다"로 비활성. 진단상 코드 정상(disabled=false·클릭 주입 시 모달 open). 세로 개편 후에도 정상.

## 세션 3 (원정 일대기 도달/재회 표시) — 요약
map-render 세션(Map.gd)과 겹치지 않는 범위에서 진행. 원정 일대기(Bookmark)가 죽은 원정만 보이고 end 도달(이 게임에서 가장 큰 사건, ~10%)은 "기록이 모래에 지워졌다"로 뭉개지던 UX 갭을 해소. 백로그 line 9의 "도달/생환 표시" 미완 항목.

## 주요 변경 (세션 3)
- `scripts/GameState.gd` — 영속 필드 `arrivals`(`{expedition, ending}`) + `mark_arrival(ending)`(중복 기록 방지, save) + save/load/reset 배선. **라우팅(go_to_*) 무관 순수 추가** — map-render 가 "공유 라우팅이니 알림" 표시한 파일이라 footprint 최소화·명시.
- `scripts/ui/Expedition.gd` — `_show_ending`에서 `GameState.mark_arrival(kind)` 1줄(엔딩 패널 뜰 때 이 원정의 도달/재회 기록).
- `scripts/ui/Bookmark.gd` — `_chronicle_line` 3분기: ① 도달·재회(arrivals, 재회=SAND 따뜻색·"건너편에서 모두와 다시 만났다" / 도달=FG·"끝에 닿았다. 다음 원정대가 이곳으로 온다") ② 스러짐(기존 deaths) ③ 아직 길 위(현재 진행 중 원정) / 지워진 기록(옛 세이브). `_arrival_of` 헬퍼(`_death_of` 미러).

## 결정 사항 (세션 3)
- **도달/재회는 새 데이터(arrivals)로, 죽음은 기존 deaths로.** 완주 원정은 게임 구조상 죽거나 end 도달 둘 중 하나(자발적 중단 없음) → 두 기록은 상호배타적. arrival 우선 분기.
- **엔딩 종류를 그대로 반영:** 순환("도달")과 재회("재회")를 일대기 문구·색으로 구분. 재회만 SAND(따뜻)로 특별하게 — 릴레이의 유일한 진짜 승리.
- **GameState 편집은 순수 추가로 한정** — map-render 세션 조율(라우팅 안 건드림). ACTIVE_WORK 에 footprint 명시.
- 밸런스 미영향(순수 표시 계층)이라 진행 중인 폰 밸런스 튜닝을 흔들지 않음.
