## 세션 3 (저녁) — 설정창 + 데이터 초기화

### 요약
타이틀에서 진입하는 설정창을 오버레이로 구현. 핵심은 데이터 초기화(저장된 세계 삭제) + 실수 방지 확인 다이얼로그.
음량 슬라이더는 placeholder 수준(master bus 즉시 반영, 저장은 아직 안 함).

### 주요 변경
- `scripts/ui/SettingsPanel.gd` (신규) — 타이틀 위 Control 오버레이. 반투명 배경(빈 곳/ESC 로 닫기),
  소리 슬라이더(master bus 연결), 데이터 초기화 버튼(위험색) → `ConfirmationDialog`(한글 버튼) → `GameState.reset_save()`.
  초기화 완료 시 `data_reset` 시그널 emit.
- `scripts/ui/Main.gd` — "설정" 버튼 추가, 통계 라벨을 멤버(`_stat_label`)로 들고 초기화 후 갱신. `SettingsPanel` preload + 진입.
- `docs/design/backlog.md` — 완료 항목 정리(설정창·데이터 초기화·이미 끝난 한글 폰트 임베드 제거), "설정 확장" 후속만 남김.
- `docs/design/known_issues.md` — `-s` 헤드리스 검증 함정(autoload 미등록 → 컴파일 실패·hang) 기록.

### 결정 사항
- **씬이 아니라 오버레이.** 설정창은 씬 전환 없이 타이틀 위에 `add_child` 로 띄운다 — 상태 유지·깜빡임 없음, 나중에 게임 중에도 재사용 가능.
- **음량은 placeholder.** 사용자 의도대로 일단 노출만(master bus 즉시 반영). 저장/복원·접근성은 backlog "설정 확장"으로 미룸.
- **확인 다이얼로그로 실수 방지.** 데이터 초기화는 되돌릴 수 없으니 `ConfirmationDialog` 한 단계를 둠. 버튼 한글("초기화"/"취소").
- **UI 코드 구성 패턴 유지.** Phase 0 관례대로 .tscn 없이 GDScript 로 UI 구성, 터치 우선(버튼 56px·슬라이더 40px).

### 검증 / 미해결
- `--import`(파싱·컴파일) + `--quit-after 5`(부팅) 둘 다 에러/경고 0 통과. `get_cancel_button()` 은 `ConfirmationDialog.new()` 직후 유효(엔진 보장).
- `-s` 단독 스크립트 검증은 autoload 미등록으로 부적합 — known_issues 에 기록. 시각적 확인(레이아웃·터치 감)은 폰/데스크톱 실기기 몫.
- 다음: 음량 저장 연결, 접근성 옵션. 그 외 백로그 후보(차단·폭풍 본구현 / 비주얼 방향 / 폰 페이싱 튜닝).

## 세션 4 (밤) — 폰 환경 쾌적화

### 요약
폰에서 쾌적하게 플레이하도록 정비. 사용자 선택: 세로/가로 둘 다 반응형, 우선순위는 "글씨·버튼 키우기 + 예방 정비".
글씨·터치 타깃을 키우고, 웹 셸에 브라우저 줌·스크롤 바운스·텍스트 선택 억제를 넣었다.

### 주요 변경
- `scripts/ui/UITheme.gd` (신규) — 폰 우선 사이즈·색 상수 한 곳에 모음(글자 크기·버튼 높이·여백·색). `make_button()` 헬퍼로
  터치 타깃(64px) 일괄 보장. 여기 숫자만 바꾸면 전 화면에 반영(한 손잡이 튜닝).
- `project.godot` `[gui] theme/default_font_size=20` — 오버라이드 없는 버튼·다이얼로그 텍스트 일괄 확대.
- `export_presets.cfg` `html/head_include` — viewport 메타(`maximum-scale=1, user-scalable=no, viewport-fit=cover`) +
  CSS(`touch-action:none`·`overscroll-behavior:none`·`user-select:none`·배경색). 핀치/더블탭 줌, 스크롤 바운스, 롱프레스 선택 억제.
- `scripts/ui/Expedition.gd` — 물·식량(가장 자주 보는 수치) 22→30, 상태/보조/상황 텍스트·죽음 문구 확대, 선택지 버튼 52→64+가로 꽉 채움,
  상단 HUD 안전 여백(28), 하단 버튼 바 여백. 캔버스 직접 그리는 흔적 태그·랜드마크 이름도 확대.
- `scripts/ui/Main.gd`·`Map.gd`·`SettingsPanel.gd` — UITheme 사이즈·색으로 통일, 버튼·슬라이더 확대. SettingsPanel 중복 색 상수 제거.
- `scripts/ui/Map.gd` — 헤더 "지도 — 원정 계획"의 한글 사이 em dash 를 가운뎃점으로 교정(house rule `no-em-dash-korean`).

### 결정 사항
- **`expand` 스트레치 특성 확인 → 고정폭은 안전.** `canvas_items+expand` 는 제약 축이 기준값(1280)과 같고 다른 축만 커진다.
  즉 논리 가로폭은 항상 ≥1280 → 패널·버튼 고정폭이 세로/가로 어디서도 잘리지 않는다. 그래서 반응형 핵심은 "오버플로 방지"가 아니라 "글씨·타깃 키우기"로 좁혀짐.
- **방향 강제 안 함.** 웹 브라우저 방향 잠금이 불안정 → 둘 다 반응형으로. PWA orientation 도 Any(0) 유지.
- **사이즈를 UITheme 한 곳에.** 화면마다 흩어진 매직 넘버 대신 상수 한 곳 — 폰 실기기로 체감 후 튜닝을 쉽게.
- **음량·세이브 등 기능은 손대지 않음.** 이번 턴은 폰 쾌적화(레이아웃·타이포·브라우저 동작)에 한정.

### 검증
- `--import`·`--quit-after 5`·웹 export(`--export-release "Web"`) 셋 다 에러 0 통과. 생성된 index.html 에 head_include(viewport-fit/touch-action/overscroll/user-select) 주입 확인.
- 실제 글씨 크기·터치감·세로/가로 레이아웃은 폰 브라우저 실기기 확인 필요(배포 후).

### 미해결 / 다음 할 일
- 폰 실기기에서 글씨 크기·버튼 간격 체감 후 UITheme 수치 미세 조정.
