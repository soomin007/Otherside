## 요약
폰 itch 복귀 후 일지 터치 먹통이 0.3.2 로도 미해결(프로브도 안 뜸 = 엔진 포커스/리사이즈 알림 자체가

- `scripts/ui/Fullscreen.gd` — ① _process 에서 JS 로 document.fullscreenElement 를 0.5초마다 감시,

  itch 래퍼 전체화면 전환이 엔진에 안 전달됨을 확인.

- 0.3.4(탭·스크림 release 기준 + 워치독) 적용 후에도 **증상 완전 동일**: 일지 열고 나갔다 오면

  새 터치가 "이미 눌린 손가락의 이동"으로 해석됨 = **고착 터치가 엔진 브라우저 입력 층(JS)에 잔존.**
  GDScript 주입 release(0.3.1~)로는 그 층이 안 닦인다는 것이 증명됨.

### 내일 첫 작업 (구체 설계 known_issues 최신 항목에)
1. **유령 드래그 재합성**(주 공략): Fullscreen._input 에서 ScreenTouch dn/up 으로 "눌린 index 집합"
   추적 → 집합에 없는 index 의 ScreenDrag 가 오면 그 위치에 dn 합성 → 이후 드래그 통과 →

3. 검증 순서: 프로브 버전 필드가 v0.3.4 였는지부터 확인(업로드 반영 여부). 0.3.4 확정인데도

살린다. 보조로 복귀 치유 때 브라우저 입력 층에 touchcancel 을 직접 쏜다. 0.3.5 빌드·zip 교체까지.

  복귀 치유 때 canvas 에 touchcancel(identifier 0~9)·pointercancel dispatch(엔진 JS 층 청소)
  ④ 프로브에 드래그 index(`ScreenDrag#n`)·재합성 횟수(`gh:n`) 표기 ⑤ `_ghost_test`(드라이버용 가드 우회).
- `project.godot` 0.3.5 · `itch_업로드/syotos_web_v0.3.5.zip` 재빌드(0.3.4 삭제) · README 빌드 절 갱신.

## 검증
- 창모드 드라이버(삭제함, `_track_ghost` 직접 호출이라 세이브 무접촉): 유령 등록 / dn 중복 없음 /
  공백 스윕 / 스윕 후 버튼 pressed 발화(end-to-end) / 정상 스트림 무개입 / 정상 up 추적 해제 /

## 결정 사항
- 재합성 공백 판정은 설계값 180ms 유지. 죽은 상태의 탭은 뗌이 최대 180ms 늦게 합성되지만

- 치유(_release_stuck_touches)가 추적 집합을 비우므로, 치유 직후 실제로 눌린 손가락도 일단 유령으로
