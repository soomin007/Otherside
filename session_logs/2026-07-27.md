# 2026-07-27 세션 로그

## 세션 1 (자정 직후, 07-26 세션 6 연속) — 0.3.3: 복귀 치유 강화 + 키보드 무한 버그 + 임베드 크기

## 요약
폰 itch 복귀 후 일지 터치 먹통이 0.3.2 로도 미해결(프로브도 안 뜸 = 엔진 포커스/리사이즈 알림 자체가
안 옴). JS 감시 기반 치유로 전환한 0.3.3 빌드. 이름칸 가상 키보드 무한 재출현 버그 수정.
임베드 크기 640×360 확정(재업로드 리셋 함정 문서화).

## 주요 변경
- `scripts/ui/Fullscreen.gd` — ① _process 에서 JS 로 document.fullscreenElement 를 0.5초마다 감시,
  상태가 바뀌는 순간 치유+프로브(엔진 알림에 의존 안 함). ② 치유에 에뮬레이션 마우스 릴리즈 주입
  (GUI 캡처 고착 해제)·gui_release_focus·일지 열려 있으면 heal_after_restore 호출 추가.
- `scripts/ui/Bookmark.gd` — heal_after_restore(): 열려 있으면 배치 재계산 + 현재 챕터를 새 컨트롤로
  재구축(낡은 컨트롤이 어떤 상태로 굳었든 무관해짐). _flipping 중엔 스킵.
- `scripts/ui/Loadout.gd` — _input: 이름칸 밖 ScreenTouch 면 release_focus → 가상 키보드 내림
  (밖을 눌러도 포커스가 남아 키보드가 무한으로 다시 열리던 폰 버그. make_input_local 로 좌표계 흡수).
- `project.godot` 0.3.3 · zip 교체 · README: 임베드 **640×360 확정**(임베드 크기가 페이지 본문 폭을
  키워 배경 어둠 채널을 침범 — 1280 금지) + zip 재업로드가 임베드 크기를 리셋하는 함정 기록.

## 결정 사항
- 임베드는 640×360 유지가 정답: 실플레이는 폰=강제 전체화면·PC=전체화면 버튼이라 인라인 크기는
  페이지 미관 문제일 뿐이고, 크게 잡으면 테마(중앙 1120px 민바닥)가 깨진다.
- 치유 트리거를 엔진 알림(FOCUS_IN·size_changed)에서 JS 직접 감시로 전환 — 0.3.2 프로브 미출현으로
  itch 래퍼 전체화면 전환이 엔진에 안 전달됨을 확인.

## 세션 2 — 일지 먹통 기전 특정 + 0.3.4

## 요약
사용자 상세 제보("복귀하면 넘김 모션이 저절로 나오고 차례/언어가 열리며 멈춤, 책갈피 사라짐")로 기전 특정.
뒤로가기 = 오른쪽 가장자리 스와이프 터치 → press 기준인 챕터 탭에 얹혀 넘김 시작 →
_run_flip 의 await frame_post_draw 가 화면 숨김(rAF 정지)과 함께 매달림 → _flipping 고착.
0.3.4 로 근본 수정 + 데스크톱 검증 드라이버 6항목 전부 통과.

## 주요 변경
- `scripts/ui/Bookmark.gd` — ① `_on_tab_input`·`_on_scrim_input` 을 press → **release 기준**으로
  (탭 밖 뗌 = 취소, 시스템 제스처는 뗌이 안 와 아무 것도 시작 못 함) ② `_run_flip` 워치독 2초
  (`_flip_serial` 회차 토큰, 매달리면 `_force_end_flip`) ③ `_force_end_flip`(덮개 제거·재배치·재구축)
  ④ `heal_after_restore` 가 _flipping 스킵 대신 강제 정리 ⑤ `debug_state()` 진단 문자열.
- `scripts/ui/Fullscreen.gd` — 프로브를 일지 열림(터치 기기) 중 상시 표시(20초 만료로 관찰 놓치던 것),
  debug_state·heal 횟수 표기 추가.
- known_issues: 기전·교훈(웹 await frame_post_draw 는 숨김 중 안 돌아옴 → 상태 잠금엔 워치독,
  커스텀 gui_input 은 release 기준이 기본값) 기록. 0.3.4 빌드·zip 교체·README 갱신.

## 세션 2 마무리 — 0.3.4 도 미해결, 프로브가 원인 층을 특정 (사용자 취침, 내일 계속)

### 오늘 마지막 상태
- 0.3.4(탭·스크림 release 기준 + 워치독) 적용 후에도 **증상 완전 동일**: 일지 열고 나갔다 오면
  책갈피 사라짐 + 차례란으로 넘어감 + 전체 무반응.
- **프로브 판독(결정타): 죽은 상태의 모든 터치가 `ev: ScreenDrag`.** 입력은 엔진까지 오는데
  새 터치가 "이미 눌린 손가락의 이동"으로 해석됨 = **고착 터치가 엔진 브라우저 입력 층(JS)에 잔존.**
  GDScript 주입 release(0.3.1~)로는 그 층이 안 닦인다는 것이 증명됨.
