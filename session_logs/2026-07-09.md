## 결정 사항
- **주기의 엔진 = 폭풍(달력 아님).** 기획서 §2에 이미 "폭풍=원정이 주기적인 이유"가 묻혀 있던 것을 표면으로 올림
  (lore 신규 창작 아님). 불규칙·긴 간격이라 "긴 시간 경과" 체감이 살고, E33 시계태엽 카운트다운과 갈라진다.
  Expedition 33 참조는 *릴레이 구조 좌표*로만 남기고, 세계 구조를 "E33 결"로 브랜딩하던 표현은 제거.
- **막간은 순수 연출.** 흔적 uses·안개를 실제로 깎지 않는다(표시상 묻힘·재안개일 뿐). 시간 기반 흔적 소멸은
  밸런스 영향이 있어 별도 결정 후 후속으로 미룸(임의로 메커닉화하지 않음).
- **막간은 죽음·순환 두 경로에만.** 첫 원정(Opening→Loadout 직행)엔 안 뜬다 — 오프닝이 곧 첫 도입이라.
- 새 대장 이름은 기존 `ExpeditionNamer`(원정대 이름 = 그 원정의 대장 자리)를 재사용, 막간→Loadout으로 연속.

## 검증

- 막간 미감: 임시 스크린샷 드라이버(창모드)로 sweep/settled 두 프레임 캡처·확인 후 삭제. 1차에서 텍스트가

  반투명 먼지벽으로, 흔적 묻힘을 전선과 동기화, 안개를 그라데이션으로 개선 후 재확인(양호).

## 세션 2 (재회 카운트 버그 발견 + 임계 8→4 + 미결 3건)

### 요약
"시체가 무슨 역할이냐"는 질문에서 출발해, 외부 테스트 공략이 **시체(죽은 자리)를 재회 카운트에 넣는 오류**를 짚어냈다.
코드 확인 결과 죽음은 `deaths` 배열이라 재회 카운트(`traces` 비-seed)에 0 기여 — 공략대로면 8이 안 차 순환만 뜬다.
사용자 지시로 재회를 "공략 알면 금방"으로 만들기 위해 임계 `REUNION_TRACES` 8→4로 낮춤.

### 주요 변경

### 결정 사항
- **시체 = 정보·정서 전용, 재회에 0 기여(의도).** `TraceData` 주석 "정보 0 정서 100" 그대로. 재회는 *남기기*로만 연다(주제: 죽음이 아니라 남김).
- **재회 임계 8→4.** 무사 도달(안 죽기)이 진짜 관문이고 그 준비(다리+스태시)가 어차피 ~3런 걸려 4가 자연히 참 → 4 밑으론 더 빨라지지도 않음(무사 도달이 바닥). 무사 도달 요구는 유지(재회의 심장 "온전히").
- 재회(계획 ~4원정)가 순환(막 굴리면 ~8원정)보다 빠른 역전 = 지식·계획 보상. "2회차 정서"는 의도(졸업 엔딩), 단 그리드가 아니라 지식이 관문이게.
