## 세션 1 (웹 가로 잠금·백그라운드 음소거 재구현 — JS 직접 호출)

### 요약
어제 넣은 두 웹 기능이 실기기에서 전혀 동작하지 않은 원인 규명·재구현.
① 가로 잠금: DisplayServer.screen_set_orientation 이 웹에 미구현 → JavaScriptBridge 로
screen.orientation.lock 직접 호출(전체화면 진입 후 0.5s·1.5s 재시도). ② 백그라운드 음소거:
탭이 숨으면 엔진 프레임 루프가 정지해 GDScript 실행 불가 → export head_include 페이지 JS 로
AudioContext 를 래핑해 visibilitychange 에서 suspend/resume. 둘 다 known_issues 기록.

### 주요 변경
- `scripts/ui/Fullscreen.gd` — _lock_landscape = JavaScriptBridge.eval(orientation.lock), 재시도 2회.
- `scripts/AudioManager.gd` — 포커스 알림 음소거 제거(웹에서 실행 불가), 주석으로 위임처 명시.
- `export_presets.cfg` — head_include 에 AudioContext 래퍼 + visibilitychange suspend/resume JS.
- `docs/design/known_issues.md` — 웹 백그라운드 GDScript 정지 / screen_set_orientation 웹 미구현.

### 미해결 / 다음
- 폰·데스크톱 재확인(강력 새로고침): 가로 자동 회전, 탭 전환·최소화 음소거.
- 폰트 서브셋(~10MB 절감 후보) 대기.
