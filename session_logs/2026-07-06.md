## 세션 2 (책장 넘김 리플 이식 — handoff_book_flip, 4d68d24)

### 요약
외부 목업(`handoff_book_flip/` — HTML 프로토+정량 스펙) 도착 → `Bookmark.FlipDeck` 로 이식 완료. 스케일 접기(FlipLeaf) 폐기.

### 구현 핵심
- **스파인 폭-투영**: 낱장 폭 = PW·|cos(e·π)|, 수직에서 0→반대편서 재확장(가로로 넘어감 — 지난 지적 3종: 솟구침·코너축·미러 전부 회피). bow 사다리꼴(자유변 2차 베지어 6분할) + UV 폴리곤 텍스처.
- **리플**: K8장 스태거(퍼짐 .45·넘김창 .5), inOutQuad+smoothstep, e 내림차순 정렬(동률 k 오름차순). 450ms.
- **명암 4종**: 곧추섬 어둠(stand·0.5), 자유변 그라디언트(정점색 — draw_polygon per-vertex color), 이동 하이라이트, 드리운 그림자(스파인→안쪽 그라디언트 폴리곤).
- **텍스처**: k=0 앞면 = 현재 페이지 화면 캡처(`get_final_transform()` 물리 픽셀 크롭). 나머지 낱장 = 불투명 양피지+괘선 더미(밑장 비침 금지). 덮이는 쪽 베이스 = 캡처, 걷히는 쪽 = 구멍(실 목표 노드 노출 — 콘텐츠 즉시 교체+같은 프레임 덮개 = 팝 없음).
- **두께 스택(§5)**: LedgerBook.thickness_cf — 넘김 동안 좌우 겹수 연속 이동.
- 절충: k=K−1 뒷면은 스펙상 "목표 페이지"지만 캡처가 1프레임 노출을 요구해 **더미로 대체**(안착 종료 시 실 노드 자연 노출 — 450ms 리플 속 인지 불가 수준). 필요 시 SubViewport 오프스크린으로 개선 여지.

### 미해결 / 다음
- 실플레이 감각 확인(특히 웹 — 캡처(get_image)가 웹 GL에서 느릴 수 있음, 프레임 히치 나면 캡처 해상도 축소 후보).

## 세션 7 (위치 반영 환경 강도 — 바람 환경음 + 지도 드리프트, 분위기 시스템 (b))

### 원인
mp3 원본의 앨범 커버가 `ffmpeg ... -c:a libvorbis`(=`-vn` 없음) 변환 때 theora 영상으로 트랜스코딩돼
ogg 에 함께 mux 됨. (godot-audio-pipeline 스킬 §2 변환 예시에 `-vn` 이 빠져 있던 게 근인.)

### 주요 변경
- `assets/bgm/*.ogg` 4곡을 원본 mp3(`assets_src/bgm_original`)에서 **audio-only 재인코딩**(`-vn -c:a libvorbis -q:a 2`, ~96k 유지)해 교체. ffprobe 로 audio 스트림만 확인.
- `known_issues.md` 에셋 처리 섹션 + `godot-audio-pipeline` 스킬(리포 밖)에 "`-vn` 필수" 교훈 기록.

### 결정 · 미해결
- 비트레이트 그대로·영상만 제거 = 변수 하나만 바꾼 테스트. **크기 거의 동일(곡당 -5~7KB)** → 영상은 정지 커버 한 장 수준이라 **이 제거만으로 소리가 안 바뀔 수도 있음**을 사용자에게 고지.
- 실행 중 Godot 에디터(다른 세션) 있어 헤드리스 임포트 생략(락 위험) — `.import` 설정 불변, 배포 CI 가 재임포트.
